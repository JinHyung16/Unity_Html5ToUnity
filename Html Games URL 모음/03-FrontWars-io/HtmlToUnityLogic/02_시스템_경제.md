원본 위치는 `[소스] Cq3gr8XO.js:<찾을 글자>`. 식은 읽고 풀어 쓴 것이다.

## 무엇인가

병력과 골드를 늘리고 옮기는 시스템이다. 매 틱 플레이어 실행이 병력·골드를 더하고, 무역선·기차가 골드를 더 벌고, 동맹·팀끼리 병력·골드를 기부한다. 관계 값은 시간이 지나면 0 으로 돌아간다.

## 계산식

### 플레이어 한 틱 순서 `[소스] nd=class{ · tick(e){`

스폰 단계에는 쉰다.
1. 관계 감소: 상대마다 0 쪽으로 0.05 씩. 절댓값이 0.1 아래가 되면 0.
2. 땅 위 건물 검사: 건물 칸 주인이 없으면 삭제, 다른 플레이어면 그 플레이어가 가져간다(방어초소는 레벨 하나 내리고 남아 있으면 가져감).
3. 죽었으면(칸 0): 골드 0, 핵 계열 뺀 유닛 삭제, 멈춤.
4. 병력 += 증가량 (`troopIncreaseRate`).
5. 골드 += 사람·네이션 100 · 봇 50 (× 골드 배율).
6. 만료된 동맹을 끝낸다.
7. 임시 금수가 3000틱을 넘으면 푼다.
8. 20틱마다 고립 조각 흡수 검사 (`02_시스템_영토공격.md`).

### 병력 · 골드 식

`00_게임개요.md` 「재화」 와 `03_데이터.md` 「경제 추가 식」 이 식 전체다. 요약:

| 무엇 | 식 |
|---|---|
| 최대 병력 | 2×(땅 칸^0.6×1000 + 50000) + 도시 레벨 합×250000 → 봇 ÷3 · 사람 max(식, 시작병력설정×10) · 네이션 × 난이도 (0.5 · 1 · 1.5 · 2) |
| 틱 증가 | min(병력 + (10 + 병력^0.73/4)×(1 − 병력/최대) × 배율, 최대) − 병력. 배율 봇 0.6 · 네이션 난이도 (0.9 · 1 · 1.1 · 1.2) · 사람 1 |
| 틱 골드 | 사람·네이션 100 · 봇 50 |
| 기차 골드 | 기차가 들른 건물마다 — 관계별 값 × (건물 레벨+1). 우호면 기차 주인도 같은 양을 받는다 `[소스] dd=class{onStop` |
| 무역선 골드 | 도착하면 출발 항구 주인과 도착 항구 주인이 둘 다 받는다. 나포된 배면 나포한 쪽만 받는다 |

화면 표시는 병력 ÷ 10 이다 (`03_데이터.md` 「문구의 파생 규칙」).

### 기부 `[소스] Sf=class{ · xf=class{ · canDonateTroops(e){`

| 항목 | 병력 | 골드 |
|---|---|---|
| 기본 양 (양 미지정) | 보내는 쪽 병력 / 3 | 보내는 쪽 골드 / 3 |
| 상한 | 받는 쪽 (최대 병력 − 현재 병력) | 없음 (아직 안 읽음) |
| 조건 | 둘 다 살아 있고 · 우호(동맹 또는 같은 팀)이고 · 설정에서 병력 기부 허용 · 그 상대에게 쿨다운 끝 | 같음 (골드 기부 허용) |
| 쿨다운 | 같은 상대에게 100틱 | 같음 |
| 성공하면 | 받는 쪽의 보낸 쪽 관계 +50 | 같음 |

- 제어판 「병력 기부하기 : 10%」 · 「골드 기부하기 : 10%」 슬라이더가 기부 양 비율로 보인다 — 명령에 담기는 양 계산은 클라에서 아직 안 읽음.

### 관계 `[소스] updateRelation(e,t){ · decayRelations(){`

- 값은 −100~100 으로 자른다.
- 매 틱 0 쪽으로 0.05 (틱당) — 100 → 0 까지 2000틱(200초).
- 바뀌는 곳: 기부 받음 +50 · 타겟 표시 당함 −40 · 동맹 수락 서로 +100 · 동맹을 깬 쪽에 대해 깨진 쪽 −200, 나머지 모든 플레이어(같은 팀 제외) −40 · 핵 동맹 파기/MIRV 발사 −100 · 네이션이 동맹 요청 거절 −20 `[소스] du=class{ · fu=class{ · Sp=class{`.
- 관계 이름 `[소스] relationFromValue(e){`: 값 < −50 적대 · < 0 불신 · < 50 중립 · 그 이상 우호. 사람에게 보이는 「태도」 가 이것이다.
- `03_데이터.md` 「태도 값」 표(−0.6 · −0.3 · 0 · 0.45)는 이 관계 이름을 네이션 동맹 정책 점수에 더하는 가중치다 — 관계 값 자체와 단위가 다르다.
