### 싱글 시작과 광고

- 시작 전 광고 함수는 플랫폼마다 광고가 끝난 뒤 판을 연다. 자체 사이트는 광고 없이 바로 연다 `[소스] BVamDUD6.js:requestInterstitialOrMidGameAd(` — CrazyGames · Poki · YouTube · MSN · Y8 은 각 SDK 에 맡기고 끝나면 연다.
- 그래서 `?crazygames` 로 연 자동 실측은 광고 콜백이 오지 않아 판이 안 열린다 `[실측]`. 자동 실측은 `https://frontwars.io/` 로 연다.
- 광고는 플랫폼 소속이라 옮기지 않는다. Unity 에서는 「게임 시작」 → 바로 판.
- 「게임 시작」 → 판 준비 끝(`[App] Game ready`)까지 약 4초 `[실측 n=1]` (맵·스프라이트 로딩 포함).

## 플레이어 명령 — 입력이 시뮬로 가는 모양 `[소스] Cq3gr8XO.js:createExec(e){`

화면 입력은 명령(intent)으로 바뀌어 턴에 실리고, 워커가 명령마다 실행 객체를 만든다. 싱글도 같은 길을 간다(`LocalServer`).

| 명령 | 담는 값 | 만드는 실행 |
|---|---|---|
| `attack` | 대상 id · 병력 | 공격 |
| `cancel_attack` | 공격 id | 공격 취소 (20틱 뒤 후퇴) |
| `cancel_boat` | 유닛 id | 수송선 되돌리기 |
| `move_warship` | 유닛 id · 칸 | 전함 이동 |
| `spawn` | 칸 | 스폰 (무작위 스폰 설정이면 무시) |
| `boat` | 대상 id · 도착 칸 · 병력 · 출발 칸 | 수송선 공격 |
| `alliance_request` · `alliance_request_reply` · `break_alliance` · `alliance_extension` | 상대 · 수락 여부 | 외교 |
| `target_player` | 대상 | 타겟 표시 (대상의 나에 대한 관계 −40) |
