상태: 학습 끝 · 실행 단계 (2026-09-21) — 동맹 요청 · 수락 · 파기 · 연장 · 배신자 · 금수 · 이모지 · 퀵채팅 · 타겟 채움 · 원본 해시 대조 22/22. 게임 쪽 파기/만료 처리 세부 남음
원본 위치는 `[소스] Cq3gr8XO.js:<찾을 글자>`. 식은 읽고 풀어 쓴 것이다.

## 무엇인가

플레이어끼리의 관계를 다룬다. 동맹(서로 공격 못 함 · 기부 가능) · 배신(동맹 중 공격/파기 → 배신자 표시) · 금수(무역 중단) · 타겟 표시 · 이모지 · 퀵채팅. 설정 「동맹 비활성화」 면 동맹 기능이 전부 막힌다.

## 계산식

### 동맹 요청 보내기 `[소스] uu=class{ · canSendAllianceRequest(e){`

보낼 수 없음: 동맹 비활성화 · 자기 자신 · 어느 쪽이 연결 끊김 · 이미 우호(동맹 또는 같은 팀) · 내가 죽음 · 같은 상대에게 대기 중인 요청이 있음 · 같은 상대에게 마지막 요청 뒤 300틱이 안 지남.
- 상대가 이미 나에게 요청을 보내 둔 상태면 새로 만들지 않고 그 요청을 수락한다 (서로 요청 = 자동 동맹) `[소스] got corresponding alliance requests, accepting`.
- 같은 상대에게 받는 쪽에 이미 내 요청이 있으면 중복이라 만들지 않는다.
- 아니면 요청을 만든다. 200틱 동안 답이 없으면 거절 처리.
- 수락·거절 모두 요청자의 「지난 보낸 요청」 에 기록된다 → 쿨다운 300틱의 기준.

### 동맹 답 `[소스] du=class{`

- 이미 우호면 무시. 요청이 없으면 무시.
- 수락: 요청 수락 → 동맹 생성(만료 = 지금 + 3000틱), 서로 관계 +100. 서로 걸려 있던 임시 금수는 풀린다(수동 금수는 남음) `[소스] acceptAllianceRequest(e){`.
- 거절: 요청 거절.
- 스폰 단계 +1 틱 안에 만들어진 요청은 네이션이 자동 거절한다 `[소스] handleAllianceRequests(){`.

### 동맹 연장 `[소스] lu=class{ · Op=class{`

- 한쪽이 연장을 요청하면 그쪽 동의를 표시. 양쪽 다 동의하면: 동의 표시를 지우고 만료 = 지금 + 3000틱, 양쪽에 「alliance_renewed」 메시지.
- 만료 300틱 전(`allianceExtensionPromptOffset`)에 연장 안내를 띄우는 것으로 보인다 — 클라에서 확인 필요.
- 플레이어 실행이 매 틱 만료된 동맹을 끝낸다.

### 동맹 파기 (명령) `[소스] fu=class{`

- 동맹이 아니면 무시.
- 파기 → 깨진 쪽의 깬 쪽 관계 −200, 나머지 모든 플레이어(깬 쪽과 같은 팀 제외)의 깬 쪽 관계 −40.
- 게임 쪽 처리 `[소스] breakAlliance(e,t){`: 깨진 쪽이 배신자도 아니고 연결 끊김도 아니면 깬 쪽을 배신자로 표시(300틱). 동맹을 목록과 양쪽에서 지우고 「BrokeAlliance」 이벤트.
- 파기 자체는 금수를 걸지 않는다. 설명 문구의 「무역 5분 중단」 은 동맹을 깬 뒤 공격하면 걸리는 임시 금수(3000틱 = 5분)로 보인다 `[소스] addEmbargo(this._owner,!0)`.
- 봇·네이션이 동맹을 공격하기로 하면 먼저 파기한다 → 같은 규칙으로 배신자가 된다.

### 동맹 만료 `[소스] expireAlliance(e){`

동맹을 목록과 양쪽에서 지우고 「AllianceExpired」 이벤트. 배신자 표시 · 관계 변화 없음.

### 배신자 `[소스] isTraitor(){ · markTraitor(){`

- 배신자 표시 = 지금부터 300틱(30초).
- 배신자 효과: 방어값 ×0.5 · 공격 받을 때 속도 ×0.8 (`02_시스템_영토공격.md`), 봇·네이션이 노린다.
- 설명 문구: 「동맹을 배신하면 30초간 배신자, 방어 50% 감소, 무역 5분 중단」 `ko.json:instructions.betray_ally`.

### 금수 `[소스] Cf=class{ · addEmbargo(e,t){ · stopEmbargo(e){`

- 명령 「시작」: 금수 추가(수동 = 임시 아님). 「중지」: 금수 삭제.
- 이미 수동 금수가 있으면 임시 금수로 덮어쓰지 않는다.
- 임시 금수: 사람·네이션끼리 공격을 시작하면 대상이 공격자에게 건다. 3000틱 뒤 플레이어 실행이 푼다.
- 무역 가능 = 서로 금수 없음 · 다른 플레이어.

### 타겟 표시 `[소스] Sp=class{ · canTarget(e){`

- 조건: 자기 자신 · 우호 상대가 아니고, 마지막 타겟 뒤 150틱 지남.
- 표시하면 대상의 나에 대한 관계 −40. 표시는 100틱 동안 동맹에게 보인다.

### 이모지 `[소스] Wu=class{ · canSendEmoji(e){`

- 받는 쪽: 한 플레이어 또는 전체.
- 같은 받는 쪽에게 50틱 쿨다운. 표시 50틱.
- 이모지 목록 55개 (순서 고정 — 명령에는 번호로 담긴다) `[소스] const Vt=`: 😀 😊 🥰 😇 😎 😞 🥺 😭 😱 😡 😈 🤡 🖕 🥱 🤦‍♂️ 👋 👏 🤌 💪 🫡 👍 👎 ❓ 🐔 🐀 🤝 🆘 🕊️ 🏳️ ⏳ 🔥 💥 💀 ☢️ ⚠️ ↖️ ⬆️ ↗️ 👑 🥇 ⬅️ 🎯 ➡️ 🥈 🥉 ↙️ ⬇️ ↘️ ❤️ 💔 💰 ⚓ ⛵ 🏡 🛡️
- 목록에 없는 번호는 무시.
- 네이션의 반응 `[소스] function Uu(e,t,n,r,i){` — 받는 쪽이 네이션이고 그 네이션이 보낸 쪽에게 이모지를 보낼 수 있을 때:
  - 🖕: 네이션의 보낸 쪽 관계 −100, 답장 무작위 하나 (🖕 😡 🤡 😞 😭).
  - 🤡: 관계 −10, 답장 (❓ 🤡).
  - 🕊️ 🏳️ ❤️ 🥰 👏: 쉬움 난이도면 관계 +15. 보낸 쪽의 네이션에 대한 관계가 중립 이상이면 답장 (❤️ 😊 🥰), 아니면 (❓ 🤡).
- 네이션이 사람에게 먼저 보내는 이모지는 사람마다 300틱, 퀵채팅은 900틱 동안 다시 안 보낸다 `[소스] claimEmojiSlot(e){ · maybeSendQuickChat(`.

### 퀵채팅 `[소스] yu=class{`

- 문구 키 「분류.문구」 를 나눠 받는 쪽과 보내는 쪽 둘 다의 채팅 이벤트로 띄운다. 대상 플레이어 이름이 `[P1]` 자리에 들어간다.
- 쿨다운은 이 실행 안에 없다 — 네이션이 보낼 때만 900틱 간격을 둔다 (위).
- 사람은 플레이어 정보 판 「퀵 채팅」 버튼 → 퀵 채팅 창에서 고른다 (카테고리 6 · 문구 57 · `04_UIUX규칙.md` 「퀵 채팅 창」).
