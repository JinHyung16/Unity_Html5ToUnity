# 02 시스템 영토공격 — Design + Client

상태: 학습 끝 · 실행 단계 (2026-09-16) — 스폰 · 공격 · 점령 · 승리 판정 원본 해시 대조 22/22 (사람 명령 판 포함)
원본 위치는 `[소스] Cq3gr8XO.js:<찾을 글자>` (워커). 식은 읽고 풀어 쓴 것이다 — 코드를 복사하지 않는다 (R11).

## 무엇인가

맵의 땅 칸을 플레이어가 나눠 갖는 시스템이다. 스폰으로 첫 칸을 받고, 병력을 보내 이웃 칸(무주지 또는 다른 플레이어 땅)을 한 칸씩 점령한다. 땅이 0 이 되면 죽고, 한 플레이어(팀)가 땅의 80%(팀 95%)를 넘으면 판이 끝난다.

## 계산식

### 스폰 `[소스] ld=class{ · function sd(`

1. 스폰 단계 안에서만 받는다. 스폰 단계가 지나면 무시한다.
2. 이미 칸이 있으면 전부 내려놓고 새 자리에서 다시 받는다 (스폰 단계 동안 자리 바꾸기 가능).
3. 받는 칸 = 누른 칸에서 4방향 이웃으로 퍼지며(BFS), 중심을 (누른 칸 x − 0.5, y − 0.5) 로 둔 원 거리² ≤ 16 인 칸 중 주인 없고 · 땅이고 · 지나갈 수 있는 칸 전부. 없으면 반경 6(거리² ≤ 36)으로 다시. 그래도 없으면 누른 칸 → 이웃 칸 하나 `[소스] function id(e,t,n=!1){`.
   - 빈 땅 한가운데면 원 안 칸 수가 스폰 크기다 — 정확한 칸 수는 `07_기대값.md` 에서 센다.
4. 처음 스폰하면 플레이어 실행(병력·골드 증가 등)을 붙이고, 봇이면 봇 AI 실행도 붙인다.
5. 스폰 단계 끝나기 10틱 전에 아직 안 고른 사람·네이션은 자동 배치된다 (봇 제외). 무작위 스폰 설정이면 틱 2 에 사람을 자동 배치한다.
- 싱글에서 사람이 스폰해도 스폰 단계는 끝까지 간다 `[실측 n=1]` — 스폰 뒤 약 9.5초 뒤 타이머가 시작됨. OpenFront 는 싱글이면 바로 끝낸다(참고) → FrontWars 는 다르다. n≥3 으로 닫는다.

### 봇 배치 `[소스] ud=class{`

- 봇 수만큼: 맵 전체에서 무작위 칸을 뽑아, 땅이고 이미 놓인 봇과 맨해튼 거리 30 이상이면 봇 스폰을 만든다. 실패가 10,000번을 넘으면 그만둔다.
- 봇 이름 = 앞말 목록 하나 + 뒷말 목록 하나 (예: 「Swiss Host」 「Dutch Horde」 `[실측]`).
- 난수 시드 = 게임 id 문자열 해시 → 같은 게임 id 면 봇 배치·이름이 같다. 해시 = 글자마다 h = h×31 + 글자코드 (32비트 정수로 자름), 마지막에 절댓값 `[소스] function P(e){`. 명령 실행기 난수는 해시+1 `[소스] new W(P(t)+1)`.

### 공격 시작 `[소스] _u (AttackExecution) init`

1. 대상이 동맹·같은 팀이면 취소.
2. 사람·네이션끼리 공격하면 대상이 공격자에게 임시 금수를 걸고, 대상에게 온 공격자의 동맹 요청을 거절한다.
3. 대상이 플레이어이고 (스폰 단계 + 50틱) 전이면 취소.
4. 보낼 병력 = 명령에 담긴 병력(사람은 floor(병력×공격 비율)) · 없으면 사람·네이션 병력/5, 봇 병력/20. 공격자 병력에서 뺀다.
5. 같은 대상에게 이미 공격 중이면 병력을 합친다 — 아직 안 읽음.
6. 공격자의 국경 칸마다 이웃 대상 칸을 우선순위 큐에 넣는다.

### 같은 판을 내기 위한 자료 구조 규칙 `[소스] gu=class{ · xm=class{ · this.random=new W(123)`

| 무엇 | 규칙 | 어기면 |
|---|---|---|
| 공격마다의 난수 | 시드가 **고정 123** — 공격 실행을 만들 때마다 같은 수열로 시작한다 | 칸 순서 · 예산 난수가 원본과 갈린다 |
| 먹을 칸 큐 | 우선순위를 **32비트 소수(Float32)** 로 담는 이진 힙. 올릴 때 부모 이상이면 멈춤, 내릴 때 작은 자식(같으면 왼쪽) · 그 자식 이상이면 멈춤 | double 로 담으면 같은 값이 갈려 먹는 순서가 바뀐다 |
| 국경 칸 집합 | 칸마다 배열 위치를 기억하고, 빼면 **마지막 칸이 그 자리로** 온다. 위치 배열은 게임 전체가 공유 | 국경 순회 순서가 바뀌어 공격 큐 순서가 갈린다 |
| 플레이어 칸 집합 | JS Set — 넣은 순서, 뺐다 넣으면 끝으로 | 스냅숏 · 흡수 순서가 갈린다 |
| 너비 탐색(bfs) | 스택(마지막에 넣은 칸부터)으로 4방향 이웃을 넓힌다 | 스폰 칸 · 건물 자리 후보 순서가 갈린다 |

### 칸 우선순위 `[소스] addNeighbors(e,t){`

우선순위(작을수록 먼저) = (난수 10~16) × (1 − 0.5 × 그 칸에 붙은 내 칸 수 + 지형값/2) + 현재 틱.
지형값 평지 1 · 고원 1.5 · 산 2. → 내 땅에 많이 둘러싸인 칸 · 평지 · 먼저 들어온 칸이 먼저 먹힌다.

### 공격 한 틱 `[소스] tick(e){if(this.attack===null)`

`00_게임개요.md` 「공격 한 틱」 이 식 전체. 순서만:
1. 후퇴 명령을 받았으면: 대상이 플레이어면 25% 잃고 나머지를 돌려받는다. 취소 명령은 받은 틱에 「후퇴 중」 으로 표시하고 20틱(2초) 뒤에 실제로 물러난다 `[소스] xp=class{ · startTick+20`. 후퇴 중에는 칸을 먹지 않는다.
2. 대상과 동맹이 됐으면 손실 없이 후퇴.
3. 칸 예산을 계산하고, 예산이 남는 동안 큐에서 칸을 꺼낸다.
4. 꺼낸 칸이 물이거나, 이미 대상 땅이 아니거나, 내 땅과 안 붙어 있으면 건너뛴다.
5. 그 칸 이웃을 큐에 더 넣고, 손실·예산을 계산해 병력을 줄이고, 대상 병력도 줄이고, 칸을 점령한다.
6. 대상 땅이 100칸 아래로 떨어지면 「방어자 죽음」 처리.
7. 병력이 1 아래면 공격 끝. 큐가 비면 큐를 다시 채우고 남은 병력을 돌려받는다.

### 칸 점령 `[소스] conquer(e,t){`

물은 점령 못 한다(오류). 지나갈 수 없는 칸은 무시. 옛 주인 칸 집합·국경에서 빼고, 새 주인에게 넣고, 그 칸과 이웃 4칸의 국경 여부를 다시 계산하고, 낙진을 지운다.

### 방어자 죽음 `[소스] handleDeadDefender(){`

대상 땅이 100칸 미만이 되면:
1. 대상의 골드 전부를 공격자가 가져간다 (메시지 「Conquered … received … gold」).
2. 10번 반복: 대상의 남은 칸마다, 공격자 땅과 붙어 있으면 공격자가 점령, 아니면 이웃 중 다른 플레이어가 점령.

### 고립된 땅 조각 흡수 `[소스] nd=class{ · removeClusters(){`

플레이어 실행이 20틱마다(시작 틱은 이름 해시로 흩뜨림), 그 사이 땅이 바뀌었을 때만:
1. 국경 칸을 8방향으로 이어 조각(클러스터)으로 나눈다. 가장 큰 조각의 경계 상자를 이름 위치에 쓴다.
2. 가장 큰 조각: 바다 해안·맵 가장자리에 안 닿고, 이웃이 전부 한 플레이어이고, 그 플레이어 국경 상자가 조각 상자를 감싸고, 그 플레이어가 우호가 아니면 → 흡수당한다.
3. 나머지 조각: 해안·가장자리에 안 닿고, 다른 플레이어 칸들의 상자가 조각 상자를 감싸면 → 흡수당한다.
4. 흡수: 이 조각을 치고 있는 비우호 이웃 중 보낸 병력이 가장 큰 공격자가 조각 전체(이어진 내 칸)를 가져간다. 그게 내 땅 전부면 골드도 가져간다. 치는 공격자가 없으면 흡수 안 됨.

### 죽음 `[소스] isAlive(){return this._tiles.size>0}`

칸이 0 이면 죽는다. 다음 틱 플레이어 실행이: 골드를 0 으로, 핵·MIRV 를 뺀 유닛을 전부 지우고, 실행을 멈춘다. 땅 위 건물은 칸 주인이 바뀌면 새 주인이 가져간다(방어초소는 레벨이 하나 내려감).

### 승리 판정 `[소스] Dp=class{`

10틱마다 (스폰 단계 제외):
1. 시간 제한을 켰고 (틱 − 스폰 단계) ≥ 분×600 이면 가장 넓은 플레이어(팀, 봇 팀 제외)가 승리.
2. FFA: 가장 넓은 플레이어의 땅 / (땅 칸 − 낙진 칸) × 100 > 80 이면 승리.
3. 팀: 팀 합계 땅 / (땅 칸 − 낙진 칸) × 100 > 95 이고 봇 팀이 아니면 승리 (봇 팀이 넘어도 승자로 안 친다).

문턱 `[소스] percentageTilesOwnedToWin(){return this._gameConfig.gameMode===b.Team?95:80}` · 판정 `e.numTilesOwned()/t*100>…` (t = numLandTiles − numTilesWithFallout). 서비스 페이지의 72% 는 홍보 글이다.
승리 뒤 이 판정은 멈춘다. 판 끝 창이 뜨고 뒤 HUD 는 그대로 보인다 → `04_UIUX규칙.md` 「판 끝 창」.
