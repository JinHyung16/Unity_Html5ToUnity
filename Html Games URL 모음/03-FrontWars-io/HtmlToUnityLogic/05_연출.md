# 05 연출 — FX

상태: 학습 끝 · 실행 단계 (2026-09-21) — 색 16/16 · 지형 10/10 · 지도 이펙트 값은 소스에서 읽어 옮김. 창 연출(디머 · 호버 · 등장 트윈)은 미측정
원본 렌더는 자체 WebGL2(지형·영토 GPU) + 스프라이트 배치다. 캔버스 2D 호출 전수표(`lineWidth` 등)는 해당하지 않는다 — 셰이더·색 함수가 본체다.

## 그리기 파라미터 전수표 — 지형 색 `[소스] BMmXchgl.js:terrainColor(e,t){`

테마 식이 둘 있다: 밝은 테마(기본 클래스)와 어두운 테마(그것을 이어받아 지형 색만 바꿈). 원본 게임은 «늘 어두운 테마 클래스»를 만든다 `[소스] BMmXchgl.js:new qt(…,new cm)` — 설정 프리셋(Dark · Light · Purple)은 클래스를 안 바꾸고 물 색 토큰과 배경만 바꾼다. 그래서 기본은 어두운 식 + 물 색 #0e2e5a, 밝은 식은 게임에서 안 쓰인다.

n = 칸 높이(0~31).

| 칸 | 밝은 테마 | 어두운 테마 |
|---|---|---|
| 지나갈 수 없음 (높이 31 땅) | rgb(72,74,84) | rgb(40,42,50) |
| 해안 땅 (물에 닿은 땅) | rgb(204,203,158) | rgb(134,133,88) |
| 해안 물 (땅에 닿은 물) | rgb(100,143,255) | rgb(50,50,50) |
| 바다 · 호수 | 물색 (70,132,180) 에서 채널마다 −10 + (11 − min(n,10)), 0 아래 자름 | 테마 물색 토큰에서 n<10 이면 채널마다 +9 − n, 아니면 물색 그대로 |
| 평지 (n 0~9) | rgb(190, 220 − 2n, 138) | rgb(140, 170 − 2n, 88) |
| 고원 (n 10~19) | rgb(200+2n, 183+2n, 138+2n) | rgb(150+2n, 133+2n, 88+2n) |
| 산 (n 20~30) | e = clamp((n−20)/10, 0, 1) → rgb(round(206+42e), round(206+42e), round(208+44e)) | rgb(round(168+46e), round(168+46e), round(170+48e)) |

## 영토 색 배정 `[소스] BMmXchgl.js:assignColor · deltaE(t,`2000`)`

- 사람 · 봇 · 네이션 · 팀마다 따로 색 목록을 쓴다 (목록 값 아직 안 뽑음).
- 이미 배정된 색이 없거나 50개를 넘으면 플레이어 id 로 시드한 난수로 고른다. 그 밖에는 남은 색 중 이미 배정된 색들과 가장 먼(CIE ΔE2000 최소 거리가 가장 큰) 색을 고른다.
- 팀 모드는 팀 색의 변형 목록에서 플레이어 id 해시로 고른다.

## 우리 이관의 연출 (소스에서 찾은 값은 그대로 · 못 찾은 것만 눈으로 맞춤)

| 연출 | 어디 | 값 |
|---|---|---|
| 색종이 · ✅ | 튜토리얼 목표 완료 | 소스 식 그대로 (26장 · 1.1초 · ✅ 1.3초 · `02_시스템_튜토리얼.md`) |
| 모서리 둥글리기 | 창 16 · 카드 · 버튼 12 · 스위치 반원 | 코드로 만든 9조각 그림 (실측 border-radius 그대로) |

이모지 글자는 Pretendard 에 없어 두부로 뜬다 → 코드로 그린 «표식» 으로 바꿨다 (원본 그림은 안 쓴다 · R11). 쓰는 길이 둘이다.
- 글 안에 섞인 이모지(이벤트 목록 · 튜토리얼 목표 칩 · 채팅): 표식 72개를 한 장(512×576)으로 구워 «TMP 스프라이트 에셋» 으로 만들고, TMP 설정의 「이모지 대체 에셋」 목록에 넣었다. TMP 가 글꼴에 없는 이모지를 그 그림으로 그린다 (`FrontWarsEmojiSpriteBake`).
- 지도 위에 뜨는 이모지: 같은 표식을 이름표 위에 띄운다 (`FrontWarsNameView.ShowEmoji`).
모르는 이모지는 말풍선으로 뜬다.
- 대응표는 `FrontWarsIconFactory.BuildMarkTable()` 한 곳에 있다. 이모지 55개 + 튜토리얼 아이콘 + 글에만 나오는 이모지 10개(✅ · 💪 · 👆 …)가 표에 있다.
- 아직 안 그리는 것: 이름표 깃발 · 건물 종류 필터를 걸었을 때의 흐림(투명도 0.3 · 흰 그림자) · 수송선 · 핵이 지나간 칸 점(영토 층에 굽는 방식).
- 규격에 없어 우리가 정한 값: 목적지 표시의 깜빡이는 주기 1초 · 고리 도는 빠르기 45°/초 · 퍼지는 고리 한 바퀴 1.4초 · 선 굵기 0.35칸.
- 철도는 칸마다 선로 조각 하나로 그린다 (`FrontWarsRailView`) — 주인 국경색 · 물 위엔 녹슨 교각 · 줌 1 부터 서서히 보인다. 선로 그림은 우리가 그렸다.
