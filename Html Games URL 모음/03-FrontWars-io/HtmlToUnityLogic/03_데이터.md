## 경제 추가 식 `[소스] Cq3gr8XO.js:trainSpawnRate(e){ · tradeShipGold(e,t){`

경제 방식(Classic / Fast)마다 식이 갈린다. 싱글 기본은 Classic.

| 식 | Classic | Fast |
|---|---|---|
| 기차 생성 간격 (역 수 e) | (e+10)×20 | min(1400, round(40×e^0.5)) |
| 기차 골드 (들른 건물 주인과의 관계) | 동맹 60,000 · 팀/기타 30,000 · 자기 15,000 | 팀 50,000 · 자기 25,000 · 동맹/기타 12,500 |
| 무역선 골드 (이동 칸 e, 항구 수 t) | floor(100,000+100e) × (1 + 2×(t−1)/((t−1)+5)) | floor(50,000+100e) × (1 + Σ_{k<t} 0.25×0.9^k) |
| 무역선 생성 간격 | floor(25 / √(기본확률 × 항구배율)). 기본확률 = 항구 3개 미만이면 1, 아니면 1 − Ht(e, ln2/10, 55) · 항구배율 = 1/(1+e/10) | e<20 이면 5 · e≤150 이면 floor((e−20)^0.85+5) · 그 위 1,000,000 |

- 골드 배율 설정이 모든 골드에 곱해진다.
- 관계는 같은 주인 → 자기, 같은 팀 → 팀, 동맹 → 동맹, 나머지 → 기타 `[소스] function vd(`.
- 보조 함수 `[소스] Cq3gr8XO.js:function Ht( · function At(`
  - `Ht(x, k, x0)` = 1 / (1 + e^(−k×(x−x0))) — S자(로지스틱) 곡선
  - `At(x, lo, hi)` = x 를 lo~hi 로 자른다
  - 무역선 기본확률은 항구 수가 55 근처에서 가장 빨리 떨어진다 (k = ln2/10).
