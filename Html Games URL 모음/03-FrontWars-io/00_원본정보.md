## 계보 [관측 — 확정 아님]

- 구조와 식별자가 오픈소스 OpenFront.io(github.com/openfrontio/OpenFrontIO)와 맞물린다: 싱글플레이 `LocalServer` · 워커 시뮬 · `turnIntervalMs` · `donateCooldown` · `deleteUnitCooldown` · `emojiMessageDuration` 등. 상류 저장소에 `src/client/LocalServer.ts` 가 있다.
- 상류 라이선스: 코드 AGPL-3.0 · 에셋 CC BY-SA 4.0. FrontWars 푸터는 「2026 FrontWars」만 표기한다.
- 사람 확정 (2026-09-15): 정본은 FrontWars 번들. OpenFront 공개 소스는 규칙·식 이해용 참고로만 읽고, FrontWars 실측·번들과 맞물릴 때만 값으로 인정한다. 어느 쪽 코드도 복사하지 않는다 (AGPL 코드 복사는 결과물 라이선스까지 묶는다).

## 프레임 구조 [실측]

```
www.crazygames.com/kr/game/frontwars-io                    (서비스 페이지)
└─ iframe#game-iframe  games.crazygames.com/ko_KR/frontwars-io/index.html   (CrazyGames 게임프레임 · 광고)
   └─ iframe#game-iframe  frontwars.io/?crazygames                          ← 게임
```

게임 프레임 origin 을 직접 열어도 같은 게임이 뜬다. CrazyGames SDK 는 이 도메인에서 `sdkDisabled` 로 꺼질 뿐 게임은 돈다 [실측 콘솔].

## 접속·재현 방법

1. 게임 프레임 origin 을 직접 연다: `https://frontwars.io/?crazygames` (중간 프레임 불필요).
2. 착수 조사는 앱 내장 브라우저에서 읽기만 했다 (콘솔 · 네트워크 · 같은 origin `fetch`). 창이 숨겨져 뷰포트가 0×0 이라 canvas 해상도는 못 쟀다.
3. 학습 실측은 로컬 Playwright(`channel:'chrome'`, `headless:true`, 뷰포트 1920×1080, `deviceScaleFactor:1`) 가 기본이다 — 홀드·드래그 입력과 뷰포트 고정이 필요하다 (공통절차 「원본을 여는 도구를 먼저 고른다」).
   - 런타임: `C:/Users/wlsgu/AppData/Local/npm-cache/_npx/e41f203b7505f1fb/node_modules/playwright`
   - 자동 실측 주소는 `https://frontwars.io/` (쿼리 없이). `?crazygames` 는 시작 전 광고 콜백을 기다려 판이 안 열린다 `[실측]`.
   - 페이지 로드 전에 넣는 값 (`addInitScript`): `frontwars:app:tutorial_seen = "true"` (튜토리얼 건너뛰고 메뉴로) · `frontwars:app:language = JSON.stringify('ko')` (한국어). 원본은 설정을 JSON 문자열로 저장한다 — 따옴표 없이 넣으면 무시된다.
   - 첫 방문 「What's new」 창은 「Close / 닫기」 를 눌러 닫는다.
   - 싱글 판: 「싱글 플레이어」 → 「호주」 → 「게임 시작」 → 콘솔 `[App] Game ready` 를 기다린다 (약 4초).
   - 실측 스크립트와 결과: 스크래치패드 `fw/probe/*.json`.
4. 스크린샷을 남기지 않는다. 실측은 구조화 덤프다 (`HtmlToUnityLogic/frames/`).

## 원본 시뮬을 node 로 돌리기 [실측 2026-09-16]

시뮬은 워커 번들 `Cq3gr8XO.js` 하나에 다 있고 결정적이라, 브라우저 없이 node 에서 돌려 틱 해시를 받을 수 있다. 스크립트: 스크래치패드 `fw/golden/run_original.js` (원본 코드는 프로젝트에 안 넣는다).

| 할 일 | 방법 |
|---|---|
| 워커 전역 | `self` 를 가짜로 둔다 — `addEventListener('message')` 를 모으고 `postMessage` 를 받는다. `location` 도 둔다 |
| 네트워크 | `fetch` 를 바꾼다: `/api/env` → `{game_env:"prod"}` · `../maps/australia/manifest.json` · `map.bin` · `mini_map.bin` |
| 맵 파일 | `FWM` + 버전 1 + 폭 · 높이(uint32 LE) + 칸 바이트 그대로. 칸은 OpenFront 파일에서 해안 비트(64)를 지운 것 = FrontWars 파일 |
| 축소 지도 | `mini_map.bin` 자리에는 OpenFront `map4x.bin` 을 넣는다 (원본 FrontWars 축소 파일은 못 받았다 — 땅 62칸 · 높이 162,950칸 차이). 우리 게임도 같은 파일을 쓴다 |
| 시작 | 번들을 `vm.runInThisContext` 로 올리고 `{type:"init", gameStartInfo, clientID}` → `initialized` 가 오면 `{type:"turns", turns:[{turnNumber, intents:[]}…]}` |
| 결과 | `game_update` 의 `updates` 안 `{tick, hash}` 를 모은다 |
| 판 설정 | 인자 `<이름> <게임 id> <봇> <네이션|null> <턴> <대조 끝 틱> [Team] [2~7|Duos|Trios|Quads|HumansVsNations]` — `gameConfig.gameMode` 는 `Free For All` · `Team`, 팀 수는 `playerTeams`. 결과 JSON 에 모드 · 팀 수 · 난이도를 같이 적는다 |
| 봇 이름 | 원본 이름 목록 둘을 우리 봇 이름 표(`FrontWarsBotNameTable`) 단어로 바꿔 끼운다 — 이름 해시가 고립 조각 검사 박자를 정해서, 이름이 다르면 해시가 갈린다 |

- 시나리오 묶기: `node combine.js <이름…>` → 정답지 JSON 한 벌 (결정성 검사기가 읽었다). 검사기와 정답지는 이관이 끝나 지웠다 (2026-09-21 · 사람 지시). 다시 재야 하면 이 방법으로 새로 만든다.
- 플레이어 갱신은 바뀔 때만 오고, 이 방식에서는 첫 값 뒤로 안 잡혔다 — 병력 · 칸은 해시로 본다.
- 대조 중 발견: 네이션 시작 병력의 강도 배율은 싱글에서 늘 1 이다 (플레이어 정보에 네이션이 안 실림).
