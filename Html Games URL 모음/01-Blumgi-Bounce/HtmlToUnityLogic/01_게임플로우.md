### 월드 선택 화면 (⠿ 버튼) [실측 — `B07_after_grid.png`]

**이 화면은 사전 회차에 없던 발견이다.**

| 요소 | 실측 내용 |
|---|---|
| 형태 | **월드 카드 캐러셀.** 가운데 카드가 확대·선택 상태, 좌우에 이웃 월드가 흐리게 |
| 카드 내용 | 월드 번호(카드 좌상단) + 농구 골대 일러스트. 선택된 카드 아래에 `WORLD 1` 문구 |
| **진행률 바** | 각 카드 위에 **퍼센트 + 게이지**. 실측 시점(W1L1 만 클리어) 에 **가운데 = `20%`**, 좌우 = `0%` ⇒ **20% = 1/5** → **월드당 레벨 5개**를 진행률로 재확인 |
| 좌우 화살표 | 좌 (약 0.05, 0.42) · 우 (약 0.95, 0.42) — 주황 삼각형 |
| 하단 | ▶ 재생 버튼 (약 0.50, 0.87) — 선택한 월드로 들어가는 것으로 보이나 **누르지 않았다 (열림 B)** |
| 상단 우측 | 이 화면에는 **🔊 · 🏠 2개만** (재시작·그리드 없음) |
| **월드 총수 단서** | 좌측(월드 1의 «이전») 카드에 **`22`** 가 찍혀 있다 ⇒ 캐러셀이 순환한다면 **총 22 월드**. 우측 카드는 `2`. **[실측 = 숫자 판독] / [가설 = 순환 여부·총수 22]** — 캐러셀을 실제로 넘겨 확인하지 않았다 |
| 잠금 표시 | **못 봤다** — 월드 2 이후 카드에 자물쇠가 있는지 **범위 밖** (0% 표기만 보인다) |

## 버튼 전수 — 인게임 2P 화면 [실측]

**2P 화면 구성 [실측 — 관측만. 규칙은 범위 밖]**

- 좌우 **대칭 2인 대전**. 좌측 P1(주황 블롭 · 파랑 공), 우측 P2(보라 블롭 · 초록 공).
- 화면 **중앙 하단에 골대 1개**를 공유한다.
- 각 플레이어 머리 위에 키 표시: **P1 = `A`**, **P2 = `M`**. 발밑에 키보드 아이콘 + 누르는 손 아이콘.
  ⇒ **2P 는 키보드 홀드 조작** (1P 의 마우스 홀드와 다르다) [실측 — 화면 표기]
- 승패 규칙 · 라운드 수 · 점수 표기는 **범위 밖** (확정표 C 로 1차 이관 범위 밖).

## 플로우 diff 체크리스트 (합격 기준 4 · 관측 범위)

이관본이 아래를 **전부** 만족해야 플로우 diff 0 이다. 각 항목의 근거는 위 실측이다.

- [ ] WELCOME → 1 PLAYER 클릭 시 **저장된 진행 레벨**로 들어간다 (항상 W1L1 이 아니다)
- [ ] 클리어 시 **사람 입력 없이** 다음 레벨로 자동 진입한다
- [ ] 실패해도 **화면이 안 바뀌고** 공만 재장전된다 (게임오버·시도 제한 없음)
- [ ] 재시작 ↺ 는 **현재 레벨만** 되돌린다 (도트 진행은 유지)
- [ ] 음소거 🔊 는 **아이콘에 X 만** 덧그리고 화면 전환이 없다
- [ ] ⠿ 는 **월드 선택 화면**으로 간다 (레벨 선택이 아니다) · 그 화면의 상단 버튼은 🔊 🏠 **2개**
- [ ] 🏠 는 **확인 팝업 없이** WELCOME 으로 간다
- [ ] 인게임 상단 버튼은 1P 에서 **4개**다 (2P 는 3개 — 단 2P 는 의도된 차이 #1 로 미이관)
- [ ] 마지막 레벨(L5) 클리어 시 **다음 월드 L1** 로 넘어가고 `WORLD` 숫자가 올라간다
- [ ] 레벨 도트는 **항상 5칸**이고 현재 레벨까지 채워진다

⚠ **원본에 없는데 엔진 기본값으로 켜지는 것**을 같이 본다 (스플래시 화면 등) — CLAUDE.md 「확정표는 프로젝트 설정까지 가야 한다」.
