## 플로우 diff 체크리스트 (합격 기준 4 · 관측 범위)

전부 만족해야 플로우 diff 0. 근거는 위 실측.

- [ ] WELCOME → 1 PLAYER 클릭 시 저장된 진행 레벨로 진입 (항상 W1L1 아님)
- [ ] 클리어 시 입력 없이 다음 레벨 자동 진입
- [ ] 실패 시 화면 불변, 공만 재장전 (게임오버·시도 제한 없음)
- [ ] 재시작 ↺ 는 현재 레벨만 되돌림 (도트 진행 유지)
- [ ] 음소거는 아이콘에 X 만 덧그리고 화면 전환 없음
- [ ] ⠿ 는 월드 선택 화면으로 (레벨 선택 아님) · 그 화면 상단 버튼은 음소거·홈 2개
- [ ] 홈은 확인 팝업 없이 WELCOME 으로
- [ ] 인게임 상단 버튼은 1P 에서 4개 (2P 는 3개 — 2P 는 의도된 차이 #1 로 미이관)
- [ ] 마지막 레벨(L5) 클리어 시 다음 월드 L1 로, `WORLD` 숫자 증가
- [ ] 레벨 도트는 항상 5칸, 현재 레벨까지 채움

원본에 없는데 엔진 기본값으로 켜지는 것(스플래시 화면 등)도 같이 본다 — CLAUDE.md 「확정표는 프로젝트 설정까지 가야 한다」.
