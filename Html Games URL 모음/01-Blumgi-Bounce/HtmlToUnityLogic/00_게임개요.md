# 00_게임개요 — Blumgi Bounce

**원본 형태: URL 제공형(블랙박스)** — 코드·에셋 접근 불가. **라이브 URL 실측이 원본이다.**
아래 값은 전부 2026-08-29 Design 회차 실측이다. **표시 없는 추측을 적지 않는다.**
못 잰 것은 `미측정(사유)` 로 남긴다 — 장르 지식으로 채우는 것이 오염이다.

## 장르 · 한 줄 정의

**홀드 차지 → 릴리즈 1발 투척 퍼즐.** 정지된 한 화면 안에서 블롭(발사대)이 머리 위 농구공을
포물선으로 던져 골대에 넣으면 레벨 클리어. 카메라 이동 없음. [실측 — `D_W1L1_start.png`]

## 한 판의 흐름 [실측]

```
[로딩 게이지 100%]
      ↓
[WELCOME]  1 PLAYER / 2 PLAYERS 카드 2장
      ↓ 1 PLAYER 클릭 (0.31, 0.34)
[W1L1]  ← 콘솔: PokiSDK.measure(Game, Level_Started, W1L1)
      ↓ 홀드 → 릴리즈 (공 1발 발사)
   ├ 골대 안 : 「YES!」 대형 연출 + 컨페티 → **자동으로 다음 레벨** (버튼 조작 없음)
   └ 빗나감  : 공이 블롭 머리 위로 **재장전** → 같은 레벨에서 무제한 재시도
      ↓
[W1L2] → [W1L3] → … (레벨 도트가 한 칸씩 채워진다)
```

- **한 판 = 레벨 1개.** 레벨 단위로 시작·종료가 끊긴다 (`Level_Started` 이벤트가 레벨마다 1회).
- **클리어 후 사람 입력이 필요 없다** — 다음 레벨로 자동 진입한다. [실측 — 스윕 중 `cleared` 직후
  별도 클릭 없이 다음 `Level_Started` 가 찍힘]
- ~~클리어 연출 후 다음 레벨 진입까지 걸리는 시간: **미측정**~~
  ✅ **해소 (8·17회차 · `05 §2` 「요약 수치」)** — **골인 +2 213 ms 에 흰 페이드 전환 시작 · +2 721 ms 완료**
  (릴리즈 기준으로는 +3 816 → +4 098 ms). 「프레임 타임스탬프 채록이 필요하다」던 사유는
  **인스턴스 수명 폴링 + rAF 채록**으로 실제로 채워졌다.
  ⚠ **W1L1 1회의 값이다** — 다른 레벨이 같은지는 아래 「미측정 목록」의 「다른 레벨의 클리어 연출」.

완주는 **v1 회차에서 W1L5 클리어 → `Level_Started, W2L1` 도착**으로 확인했고 [실측 `w1log.jsonl`],
레벨별 홀드값은 그 뒤 **레벨 귀속을 고친 v2 · l4b 회차**에서 다시 재서 위 표에 적었다.

⚠ 위 값의 정확한 의미 — **오해를 막기 위해 명시한다.**

- 이 값은 **「발사점 (0.5, 0.5) 고정 · 격자 스윕에서 처음 성공한 홀드」**다.
  **최소 클리어 홀드도, 유일한 정답도 아니다.**
  ~~성공 구간(허용 오차)의 폭은 **미측정**.~~ ✅ **해소 (11회차 · `07 §12-b`)** —
  force 축 전수 스윕(n = 141)으로 레벨별 성공 창이 나왔다. 아래 「미측정 목록」의 같은 줄과 같다.
- **★ W1L4 는 200 ms 격자를 13발 전부 빗나갔다.** 100 ms 격자로 다시 재서 **250 ms** 에서 잡았다.
  ⇒ **성공 구간이 좁은 레벨이 존재한다** — 유니티 골든 벡터는 레벨당
  **실패-성공-실패 3점**으로 **구간의 양쪽 경계**를 잡아야 한다 (`03_데이터.md` 「W1L4」).
- **같은 홀드값이 회차마다 다른 결과를 낸 사례가 있다** — W1L4 를 v2 회차는 600 ms 로 못 깼는데
  l4 회차는 600 ms 반복 발사로 깼다. **원본 이상 «후보» — 원인 미확증** (`03_데이터.md` 참조).
- **포인터 위치는 결과를 안 바꾸는 것으로 보인다** `[부분 실측]` — W1L1 에서
  `(0.5,0.5)` 600 ms 와 `(0.20,0.80)` 600 ms 가 **둘 다 클리어** [실측 `P1_W1L1_hold600_aimLowLeft.png`].
  ~~**1레벨 2점만 재본 것이라 확정이 아니다 — 미측정.**~~
  ✅ **해소 (2·7회차 · `02 §6` · `07 §4`)** — 「보이는 것」이 아니라 **확정**이다.
  게임이 읽는 입력은 `forceShoot_P1` **하나**이고(`07 §9-b`), 마우스 위치 무관 벡터를
  **홀드 700 ms 고정 · 포인터를 흩뿌려** 따로 냈다(`07 §4`).
