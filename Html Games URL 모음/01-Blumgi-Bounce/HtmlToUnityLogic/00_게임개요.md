## 장르 · 한 줄 정의

홀드 차지 → 릴리즈 1발 투척 퍼즐. 정지된 한 화면에서 블롭(발사대)이 머리 위 농구공을 포물선으로 던져 골대에 넣으면 클리어. 카메라 이동 없음. [실측 — `D_W1L1_start.png`]

## 한 판의 흐름 [실측]

```
[로딩 게이지 100%]
      ↓
[WELCOME]  1 PLAYER / 2 PLAYERS 카드 2장
      ↓ 1 PLAYER 클릭 (0.31, 0.34)
[W1L1]  ← 콘솔: PokiSDK.measure(Game, Level_Started, W1L1)
      ↓ 홀드 → 릴리즈 (공 1발 발사)
   ├ 골대 안 : 「YES!」 대형 연출 + 컨페티 → 자동으로 다음 레벨 (버튼 조작 없음)
   └ 빗나감  : 공이 블롭 머리 위로 재장전 → 같은 레벨에서 무제한 재시도
      ↓
[W1L2] → [W1L3] → … (레벨 도트가 한 칸씩 채워진다)
```

- 한 판 = 레벨 1개. `Level_Started` 이벤트가 레벨마다 1회.
- 클리어 후 입력 불필요, 다음 레벨 자동 진입. [실측 — 스윕 중 `cleared` 직후 클릭 없이 다음 `Level_Started`]
- 클리어 연출 → 다음 레벨 진입 시간: 해소 (8·17회차 · `05 §2` 「요약 수치」). 골인 +2 213 ms 흰 페이드 전환 시작 · +2 721 ms 완료 (릴리즈 기준 +3 816 → +4 098 ms). 인스턴스 수명 폴링 + rAF 채록으로 잼. W1L1 1회 값 — 다른 레벨은 「미측정 목록」의 「다른 레벨의 클리어 연출」.

## 재화 [실측 관측 범위]

재화(코인·젬·별·점수) 관측 못 함. 월드1 전 구간에서 숫자 카운터·통화 아이콘 없음.
상단 UI 는 `WORLD n` 표기 + 레벨 진행 도트 + 우상단 버튼뿐. [실측 — `F05_topbar.png`]

### 월드1 완주 기록 [실측] — 합격 기준 1

재현: `blumgi_world1.mjs` — 레벨마다 홀드 200~2600 ms 를 200 ms 격자로 스윕, 발사 후 4.2초 대기하며 다음 레벨 `Level_Started` 도착으로 클리어 판정. 발사 지점은 iframe 중앙 `(0.5, 0.5)` 고정.

| 레벨 | 클리어 홀드 [실측] | 같은 회차에 빗나간 홀드 | 시작 캡처 | 클리어 직후 캡처 |
|---|---|---|---|---|
| W1L1 | 600 ms | 200 · 400 | `V_W1L1_start.png` | `V_W1L1_clear_hold600.png` |
| W1L2 | 800 ms | 200 · 400 · 600 | `V_W1L2_start.png` | `V_W1L2_clear_hold800.png` |
| W1L3 | 600 ms | 200 · 400 | `V_W1L3_start.png` | `V_W1L3_clear_hold600.png` |
| W1L4 | 250 ms | 200 · 400 · 600 · 800 · 1000 · 1200 · 1400 · 1600 · 1800 · 2000 · 2200 · 2400 · 2600 (200 ms 격자 13발 전부 실패) | `V_W1L4_start.png` | `L4B_clear_hold250.png` |
| W1L5 | 250 ms | (없음 — l5 회차 첫 발) | `D_W1L4_start_game.png` (파일명 주의) | `V2_W2L1_start.png` |
| → W2L1 도달 | — | — | `D_W2L1_world2_start_game.png` | — |

월드1 5레벨 완주 — 합격 기준 1 충족 (관측 범위). 완주는 v1 회차 W1L5 클리어 → `Level_Started, W2L1` 도착으로 확인 [실측 `w1log.jsonl`]. 레벨별 홀드값은 레벨 귀속을 고친 v2 · l4b 회차에서 다시 잼.

값의 의미:

- 「발사점 (0.5, 0.5) 고정 · 격자 스윕에서 처음 성공한 홀드」. 최소 클리어 홀드도 유일한 정답도 아니다.
  성공 구간 폭: 해소 (11회차 · `07 §12-b`) — force 축 전수 스윕(n = 141)으로 레벨별 성공 창 산출. 「미측정 목록」 같은 줄.
- W1L4 는 200 ms 격자 13발 전부 빗나감. 100 ms 격자로 다시 재서 250 ms 에서 잡음.
  성공 구간이 좁은 레벨이 있다 — 유니티 골든 벡터는 레벨당 실패-성공-실패 3점으로 구간 양쪽 경계를 잡는다 (`03_데이터.md` 「W1L4」).
- 같은 홀드값이 회차마다 다른 결과: W1L4 600 ms 를 v2 는 못 깸, l4 는 반복 발사로 깸. 원본 이상 후보 — 원인 미확증 (`03_데이터.md`).
- 포인터 위치 무관 `[부분 실측]` — W1L1 에서 `(0.5,0.5)` 600 ms 와 `(0.20,0.80)` 600 ms 둘 다 클리어 [실측 `P1_W1L1_hold600_aimLowLeft.png`].
  해소 (2·7회차 · `02 §6` · `07 §4`) — 확정. 게임이 읽는 입력은 `forceShoot_P1` 하나(`07 §9-b`). 홀드 700 ms 고정 · 포인터 흩뿌림으로 마우스 위치 무관 벡터를 따로 냄(`07 §4`).

| 사운드 음소거 상태 저장 | 해소 (17회차) — 저장됨. 7키에 `AudioMute "0"` (`Sound "8"` · `Music "5"` 도). 값이 실제로 뒤집히는 것은 안 봄 — 키 존재가 근거 |
