## 프레임 구조 [실측] — ★ 게임은 **3단째** 프레임에 있다

```
poki.com/kr/g/undead-slayer                                   (서비스 페이지 · canvas 없음)
└─ iframe name="gameFrame"  games.poki.com/458768/<uuid>?…    (중계 · canvas 없음)
   └─ iframe name="gameframe"  <uuid>.gdn.poki.com/<uuid>/index.html?…   ← ★ 여기에 canvas
```

⚠ **첫 iframe 에서 canvas 를 못 찾았다고 블랙박스로 결론내지 않는다** (PD 「원본 형태 판정」 [사고]).
프레임 전수 순회(`page.frames()`)로 3단째에서 canvas 를 찾았다.
