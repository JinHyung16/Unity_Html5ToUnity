# paths.md — 밟은 경로 지도 (Undead Slayer · 회차 12)

**원본을 «실제로 플레이하면서»** 사건이 난 프레임의 씬 그래프를 텍스트로 뜬 것이다.
규격은 `분석로직.md` 「frames/ · motion/ · paths.md」. 뜨는 도구는 스크래치패드의 `dump/dump.js`
(Playwright + PixiJS 씬 그래프 후킹), 우리 쪽은 `Tools/Verify/UndeadFrameDumpPlayCheck.cs` 다.

## 경로

| 경로 | 시작 → 끝 | 사건 순서 (frames/ 번호) | 봇 조작 | 결말 |
|---|---|---|---|---|
| **full** (부활) | 시작 → 첫 사망 → **「부활」** → 계속 | `000` 시작 → `001` 전투 시작 → `002` 3s → `004` 「도와줘!」(전사 등장) → `008·009` 레벨 업/선택 → `012` 30s → `018` 60s → `042` **「부활?」** → `043` 부활 직후 → `044` 레벨 업(모두 받기!) | 위협 회피 › 보석 › 포인터 · **45초부터 가만히 서서 죽는다** | 부활 뒤 계속 (80초에서 채록 종료) |
| **decline** (거절) | 시작 → 첫 사망 → **「아니요」** | `000`~`034` 같은 흐름 → `035` **「부활?」** → `036` 거절 직후 → `037` **로비** | 같음 | **로비(사원) 화면** — `lobby_task_npc_*` · `lobby_portal_graveyard_open` · `lobby_portal_winter_locked` 가 뜨고 히어로가 (875, 608) 에 선다 |

⚠ **「아니요」의 도착지가 «로비»라는 것이 이 채록으로 처음 실측됐다** — 회차 11 까지는 「미측정」이었고
우리는 대기 화면으로 되돌리고 있다(의도된 차이 5). 로비 자체는 이관 범위 밖(확정표 A)이라 그대로 둔다.

## 이 채록으로 드러난 것 (회차 12 정정 목록)

| 무엇 | 원본 | 회차 11 까지 우리 |
|---|---|---|
| 첫 퀘스트 시작 | 전투 시작 **2초 뒤** (시계) · 전사는 그때 히어로 기준으로 놓인다 | 0초부터 전사·말풍선·포인터가 보였다 |
| 과제 포인터 | 대상이 화면 밖일 때만 · 화면 가장자리를 따라 움직인다 | 좌하단 **고정** (58, 519) |
| 사망 → 「부활?」 | **1초** 동안 게임이 더 돈다 · 두 번째 죽음은 곧장 끝 | 즉시 정지 · 매번 「부활?」 |
| 부활 | 체력 **4** · 반경 200 전멸 + 밖 80% · 30초 난이도 완화 | 체력 만땅 · 그 밖에 없음 |
| 죽은 히어로 | 화면에서 **사라진다**(체력바도) | 시체가 남아 있었다 |
| 떠오르는 문구 | **일곱 갈래**가 각각 다른 수명·크기·색 · 적은 «맞을 때마다» | 한 벌(0.35초) · 적은 «죽을 때만» · 피격 팝업 없음 |
| 모닥불 | `fire` 3컷 ×2.5 + 하트 입자 · 「최대 체력」/「화염 소진!」 | `fireplace` 정지 그림 하나 · 두 문구 없음 |
| 박쥐 크기 | `min(9, 4 + 0.35 × 웨이브)` — 스폰 때 정해진다 | 상수 4 |
| 고른 카드 배율 | `1.08` (**호버를 덮는다**) | `1.08 × 1.04 = 1.123` (곱했다) |

## 우리 쪽도 «경로마다» 한 번씩 밟는다

```bash
UNDEAD_DUMP_PATH=full    PLAYMODE=1 bash Tools/unity-batch.sh JinHyung.EditorTools.UndeadFrameDumpPlayCheck.RunAll
UNDEAD_DUMP_PATH=decline PLAYMODE=1 bash Tools/unity-batch.sh JinHyung.EditorTools.UndeadFrameDumpPlayCheck.RunAll
```

봇은 30초까지 «회피 › 보석»으로 놀다가 **일부러 서서 죽는다**(원본 봇과 같은 방식) → 「부활?」에서 경로가 갈린다.

| 경로 | 우리 결말 | 원본 결말 | 판정 |
|---|---|---|---|
| full | 부활(체력 4 · 반경 200 전멸 · 난이도 완화) 뒤 전투 계속 | 같음 | 프레임 대조 통과 |
| decline | **대기 화면**으로 돌아간다 | **로비(사원)** | **의도된 차이 5** — 로비는 이관 범위 밖(확정표 A) |

## 대조 방법

```bash
python dump/diff_frames.py <원본 frames 폴더> <우리 덤프 폴더> <보고서.md>
```

같은 사건끼리 이름으로 줄을 맞춰 **중심 좌표 · 크기 · 알파 · 글자 크기 · 문구**를 본다.
지형 씨앗(의도된 차이 6)과 진행 상황으로 자리가 달라지는 것(나무·모닥불·적·보석·팝업·포인터)은
**크기와 존재만** 보고, 난이도 곡선은 `motion/` 시계열로 따로 본다.
