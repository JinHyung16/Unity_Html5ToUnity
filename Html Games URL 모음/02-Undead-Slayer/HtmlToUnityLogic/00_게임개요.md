# 00_게임개요 — Design (Undead Slayer)

**상태: 작성 중** · 회차 1
모든 값에 **[실측] + 재현 방법**. 못 잰 것은 `미측정(① 도구 없음 / ② 상태 못 맞춤 / ③ 하네스 없음)`.

## 한 판의 흐름 [실측 · 회차 1]

```
(로비 「사원」)  ─ 포털 선택 ─▶  바이옴 진입
                                   │
                                   ▼
                          「시작」 버튼 (맵 위 · 화면 중앙)
                                   │  클릭/탭
                                   ▼
        ┌────────────── 전투 루프 ──────────────┐
        │ 이동(WASD/조이스틱) · 자동 사격 · 적 처치  │
        │ 보석(XP) 수집 → 경험치 누적              │
        │ HUD: 처치 n/목표 · 경과 시간 · 레벨 · 거리(m) │
        └───────────┬──────────────────────────┘
                    │ 경험치 만땅
                    ▼
              「레벨 업!」 — 업그레이드 카드 **3장 중 1장** 선택 (게임 일시정지)
                    │
                    ▼  레벨 +1 · 처치 목표 갱신 (레벨1=15 → 레벨2=40 [실측])
              전투 루프로 복귀
                    │
        ┌───────────┴───────────┐
        │ 사망                    │ 과제 완료
        ▼                        ▼
  「부활?」 (카운트다운 8 [실측])   「과제 완료!」 → 「사원으로」 / 「계속」
   · 부활 / 아니요
```

⚠ **이관 범위(확정표 A)는 «바이옴 1 한 판»이다** — 로비·포털·겨울 황무지는 관측만 하고 이관하지 않는다.
단 **「사원으로」 버튼이 원본 종료 경로**이므로 그 자리는 남긴다 (도착지는 PD 판정).

## 재화

| 재화 | 획득처 | 소비처 | 표기 | [실측] 재현 방법 |
|---|---|---|---|---|
| **경험치(XP)** | 적 처치 시 떨어지는 보석 수집 | 레벨업 | `+3 XP` 팝업 [실측] · 아이콘 `gem`/`gem_red`/`gem_icon` | `us/run.js` 텍스트 채록 |
| **과제 보상** | 과제 완료 | 겨울 황무지 포털 잠금 해제(**2개**) | 「과제 보상」 · `chest_reward` | locale `portalWinterUnlockRequirement` |
| 체력 | 모닥불 회복(`fire`) · `heart` | 피격 | `heart` | locale `taskRestoreHp*` · 아틀라스 |
