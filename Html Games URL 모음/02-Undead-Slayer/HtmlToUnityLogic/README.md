# HtmlToUnityLogic — 학습 단계 산출물 (Undead Slayer)

원본을 **실제로 돌려 보며** 파악한 것을 정리한다. 규격은 `분석로직.md` 「HtmlToUnityLogic/」+「URL 제공형」.
**URL 제공형(코드 파일 없음)** — 「원본 위치」 컬럼은 전부 **[실측] + 재현 방법**이다. `파일:줄` 은 없다.

접속·재현 방법과 프레임 구조는 **`../00_원본정보.md`** 가 정본이다. **재기 전에 그것부터 읽는다.**

> ★★ **재기 전에 `99_원본지도.md` 를 먼저 읽어라.** 이 게임은 **블랙박스가 아니다** —
> PixiJS 8.15.0 씬 그래프를 통째로 직독할 수 있고, 접근법 4단과 **이 게임 고유의 함정 6개**가 거기 있다.
> 모르고 재면 회차가 통째로 날아간다.
