## 이 문구들이 드러내는 구조 [실측에서 파생]

| 무엇 | 근거 키 |
|---|---|
| **로비(「사원」)가 있다** — 판이 끝나면 돌아간다 | `returnToLobby` = 「사원으로」 · `taskCompletionMessage` |
| **포털 2종** — 묘지(바이옴 1) · 겨울 황무지(잠김) | `portalGraveyardName` · `portalWinterName` · `portalWinterUnlockRequirement`(「과제 보상 2개를 받아 잠금 해제」) |
| **과제(task) 4종** | `taskActivateTrees*` · `taskKillEnemiesWithDash*` · `taskRestoreHp*` · `taskSaveSheep*` |
| **스킬 4종** | `skillDashName` 돌진 · `skillFlashMoveName` 섬광 이동 · `skillBlazingTrailName` 불타는 자취 · `skillWinterPulseName` 겨울 파동 |
| **업그레이드 축** | `damage` · `fireRate` · `bullets` · `projectile` · `radius` · `collectRadius` · `runSpeed` · `fullHealth` · `speed` · `lightning` |
| **무기 해금** | `unlockNewWeapon` · `newWeaponLightning` |
| **사망 시 부활 선택** | `revive` · `no` (제한 시간 카운트다운 관측 — 「8」) |
| **기록** | `bestLevel` · `bestTime` |
| **모바일 조작** | `swipeToDash` = 「스와이프하여 돌진」 → **모바일은 스와이프로 돌진** |
| **키보드 조작** | `keyboardSpace` = 「스페이스」 → 스페이스 키에 기능이 걸려 있다 |

## ★★★ 회차 9 — 번들 소스 직독 (정본은 이 절이다)

**근거 등급 ①(소스 직독).** 아래는 원본 번들에서 읽은 저작 상수·식이고, 앞 절들의 실측치는
「식이 맞는지 확인한 근거」로만 남긴다. 값이 갈리면 **이 절이 이긴다**.

### 전투 루프
| 항목 | 값 |
|---|---|
| 히어로 이동 | `0.17 px/ms × heroMoveSpeed(1)` = **170 px/s** · 대각 정규화 · 램프 없음 · 시작 **(1620, 1010)** |
| 히어로 체력 | **7** · 접촉 피해 **1** · 첫 겹침 대기 200ms · 공격 간격 1000ms · 무적 **1000ms** · 빨강 200ms · 100ms 깜빡임(알파 0.3) |
| 충돌 | **AABB** — 히어로 `(-5,-30,10,30)` · 적 `(-15,-45,30,45)` · 총알은 원 r12 · 불덩이 원 r18 |
| 사격 | 간격 **`350ms / heroBulletFireRate`** · 총구 `(0,−20)` · 피해 2 · 속도 0.7 px/ms · 사거리 1.5×화면 긴 변 · 넉백 2 |
| **조준** | **마지막에 맞힌 적 유지** → 죽으면 **화면 안 최근접** |
| 적 이동 | 직선 추격(거리>5) · 속도 개체마다 **±10%** · 넉백 감쇠 0.92/프레임 · **적끼리 분리 없음** · 화면 밖 5초면 재배치 |
| 보석 XP | **= 그 적의 최대 체력** · 수집 반경 180 · 낙하 g=8e-4 · 1회 바운스 0.4 · 비행 400ms |
| 카메라 | **지수 추적** `1−0.9^(dt/16.667)` · 화면 중앙 +20 |

### 스폰 — «위협 예산»
```
wave = floor(t/20s) ; onboarding(첫 판)이면 wave>6 일 때 wave−6
boost = 1 + 0.015·wave + 0.1·floor(wave/10)
r = 16·0.02·(wave+4)·0.01·(dtMs/6)·boost        ← 매 프레임
종류마다 budget += r × 배수 ; 20ms 판정마다 우선순위 순으로 비용을 낼 수 있으면 스폰
```
| 종류 | HP | 속도 | 해금 | 비용 | 예산 배수 | 비고 |
|---|---|---|---|---|---|---|
| enemy1 | 3 | 40 | 0 | 3 | 3 (wave<12) → 2 | 초기 예산 15 |
| enemy2 | 15 | 80 | 2 | 15 | 1 | |
| enemyBat | 23+23w | 110 | 3 | 23+23w | 1 | 해금 즉시 1마리 · 크기 4+0.35w (max 9) |
| enemyEye | 25 | 90 | 4 | 25 | 1 | |
| enemyRevenant | 40 | 70 | 12 | 40 | 3 | |
우선순위 `bat · revenant · eye · enemy2 · enemy1`. 스폰 자리 = 화면 사각형 밖 50px 네 변.

### 레벨 · 업그레이드
- 목표 **식**: `2→15 · 3→40 · 그 밖 round(30·t·(1+⌊t/5⌋)·(1+0.5⌊t/10⌋))`
- 카드 3장 = **가중치 비례 비복원**. 풀 8종: 발사속도(+0.3 · w1) · 피해(×2 · w1) · 번개+1(w = 번개<1?0 : 0.25/(1+n)) · 번개속도(+0.0005 · w0.75) · 번개반경(+14 · w0.75) · 번개피해(+50% · w0.75/1.5) · 이동(+0.15 · w0.5) · 수집(+54 · w0.5)
- **덧셈 누적**. 「모두 받기!」= 보상형 광고.

### 번개 (궤도 무기)
구슬 r25 · 중심 `hero+(3,−25)` · 반경 `heroLightningRadius`(70) · 각속도 `0.0025 rad/ms` · **한 바퀴마다 재타격** · 피해 `heroLightningDamage`(2) · 넉백 1 · 8컷 64×48 scale 0.75 · 0.3/틱.
