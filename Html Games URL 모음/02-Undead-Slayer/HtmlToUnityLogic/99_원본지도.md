# 99_원본지도 — PD 병합 (Undead Slayer) · 실측 세션 지도

상태: 작성 중 · 회차 1
URL 제공형이라 코드 지도 대신 실측 세션 지도로 대체한다.

## 먼저 읽어라 — 이 게임은 블랙박스가 아니다

엔진은 PixiJS 8.15.0, 씬 그래프를 통째로 직독할 수 있다. [실측 · 회차 1]
화면 픽셀 추적은 불필요. 재기 전에 아래 접근법을 그대로 쓴다.

### 접근법 — 4단

| # | 무엇 | 어떻게 |
|---|---|---|
| 1 | 게임 프레임 찾기 | `page.frames()` 전수 순회 → `document.querySelector('canvas')` 가 있는 프레임. 3단째 (`poki.com` → `games.poki.com` → `*.gdn.poki.com/…/index.html`). URL 의 uuid 는 버전마다 바뀌어 하드코딩 금지 |
| 2 | 모듈 직접 import | 이미 로드한 청크를 `await import('<gdn>/assets/<chunk>.js')` 로 부르면 캐시된 모듈 네임스페이스가 온다. 청크 URL 은 네트워크 로그로 모은다 |
| 3 | prototype 후킹으로 루트 잡기 | export 중 `prototype.render` / `prototype.addChild` 를 가진 클래스를 전부 감싼다. 다음 프레임에 `this`(렌더러)와 컨테이너가 잡힘 → `parent` 를 타고 올라가면 루트(stage) |
| 4 | 아틀라스 역인덱스로 이름 붙이기 | 스프라이트 `texture.frame`(아틀라스 안 사각형)을 `main.json` 프레임 사각형과 포함 관계로 매칭하면 개체를 이름으로 센다. 서브렉트면 프레임 인덱스와 프레임 수까지 나온다 |

주의: 「전역에 없다」는 「엔진이 없다」가 아니다. 1차 스캔에서 `window` 에 `c3_*`·`Phaser`·`unityInstance` 가 없었지만, 실제 단서는 네트워크 청크 이름(`WebGLRenderer-*.js` · `SharedSystems-*.js` = Pixi v8 코드 스플릿)과 rAF 콜백 소스(`this._requestId … this._head.next` = Pixi Ticker)였다.

### 함정 — 이 게임 고유

| # | 함정 | 내용 |
|---|---|---|
| 1 | 모든 창이 씬에 항상 있다 | 「부활?」·「과제 완료!」·「레벨 업!」 텍스트가 시작 화면에서도 트리에 존재, `visible` 로만 켠다. 조상까지 거슬러 보이는지 판정하지 않으면 플로우 diff 가 전부 오탐 |
| 2 | 레벨업 카드 선택은 2단계 | 카드를 고른 뒤 하단 「선택」 버튼을 눌러야 확정. 카드만 누르면 게임이 정지한 채 멈춘다 (타이머 안 감) |
| 3 | 레벨업 중에는 게임이 정지한다 | 타이머 멈춤 [실측]. 자동 채록이 여기서 무한정 대기 |
| 4 | Poki iframe 이 16:9 를 강제한다 | 뷰포트를 바꿔도 1031×580 / 836×470 / 640×360 만 나온다. 비 16:9 캔버스 관측 불가 |
| 5 | `Ticker.shared` 에는 리스너가 없다 | 게임이 자체 Ticker 사용. `Ticker.shared._head` 만 보면 빈다 — prototype 후킹으로 간다 |
| 6 | 난독화된 클래스명 (`we` · `vu` · `Lh` …) | 이름을 사양으로 쓰지 않는다. 역할은 좌표·자식 수·켜지는 시점으로 판정 |
