### ★★ 지형 = **24×24 타일 격자** [실측 · 회차 2 · Mesh 지오메트리 직독]

> **[정정]** 회차 1 에 「타일맵이 아니다 — 메시 한 장이다」라고 적었다. **틀렸다.**
> 그건 **그리는 방식**(배칭)이었고 **내용은 타일 격자**다. 지오메트리를 열어 보고서야 갈렸다.
> 원장 「오염된 내용」에 등재.

| 항목 | 값 | 근거 |
|---|---|---|
| 정점 수 | **6732** (`aPosition` 13464 float) | `geometry` 직독 |
| 인덱스 수 | **10098** → **쿼드 1683개** | 같음 |
| 쿼드 크기 | **24 × 24 world px** — 정점이 `1008,1032,1056` 처럼 **24 간격 격자**에 놓인다 | 같음 |
| 텍스처 | `biomes.png` **456 × 2040** → **19 × 85 = 1615 타일** (24×24) | `texture.source` |
| UV | 타일 하나가 u 0.159~0.2094(≈23px) · v 0.0002~0.0115(≈23px) — **24px 칸에 0.5px 인셋** | 같음 |

→ **확정표 E 정정**: **칸 = 그림이 성립한다. Unity Tilemap 이 맞는 선택이다.**
타일 크기 **24×24 world px** · 타일셋 원본 격자 **19×85**.
### 타일 배치 [실측 · 회차 4 · UV 전수 역산]

| 항목 | 값 |
|---|---|
| **그려지는 창** | **51 × 33 칸 = 1683** — 쿼드 수와 **정확히 일치**한다 (24×24 칸 · 1224 × 792 world px) |
| 창 위치 | world x 1392~2592 · y 600~1368 [이 회차의 카메라 기준] |
| 정점 격자 | **24 배수에서 벗어난 정점 0개** |
| UV | 타일 인덱스 = `(u−1)/24`, `(v−1)/24` — **1px 인셋**이 들어 있다 |
| **쓰인 타일 종류** | **39종** (타일셋 19×85 = 1615칸 중) |
| 최다 타일 | `(3,0)` **699칸** = 기본 바닥 · 그다음 `(3,2)` 158 · `(4,1)` 85 |

⚠ **창은 카메라를 따라 스트리밍된다** — 화면(1031×580)보다 한 칸씩 넓다.
⚠ **맵 «전체» 데이터는 미측정**이다. 절차적 생성인지 저작된 맵인지 확인하지 않았다 —
카메라를 옮겨 가며 같은 칸이 같은 타일을 주는지 보면 갈린다.

⚠ **fps 를 코드 `const` 로 두지 않는다** — **ScriptableObject 에셋**에 넣는다
