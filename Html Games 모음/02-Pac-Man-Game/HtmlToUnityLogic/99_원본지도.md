## `index.html`

| 줄 | 무엇 |
|---|---|
| 23~35 | 헤더 — 제목 · 점수 · 목숨 · Restart 버튼 |
| 37~43 | `<canvas id="gameCanvas" width="560" height="620">` + 안내 문구 |

⚠ **캔버스의 `width`/`height` 속성(560×620)은 script 가 덮어쓴다** —
`canvas.width = cols * corridorTile` = 28*20 = **560**, `canvas.height = rows * corridorTile` = 31*20 = **620**.
우연히 같은 값이라 눈에 안 띈다. **진실은 script 쪽이다.**
