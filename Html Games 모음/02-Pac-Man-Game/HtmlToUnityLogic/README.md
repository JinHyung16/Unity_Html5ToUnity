이 폴더는 그것을 **읽을 수 있는 표로 옮긴 것**이다.

⚠ **채우지 않은 칸은 「해당 없음」이 아니라 「아직 안 잰 것」이다.**
아래 상태표가 그 구분을 유지한다 — **「미작성」이 하나라도 있으면 학습 단계는 안 끝났다.**

## 이 게임의 특이점 — 첫 게임(Candy Crush)과 다른 축

| 무엇 | 왜 다른가 |
|---|---|
| **캔버스 직접 드로잉** | DOM 요소가 아니라 그리는 코드가 곧 그림이다 — **원본에 이미지 파일이 0개**다 |
| **실시간 이동 (dt)** | 고정 틱이 아니라 `requestAnimationFrame` + `deltaSeconds` — 프레임 독립 |
| **유령 AI** | 자율 개체. 추적 규칙을 실측해야 한다 |
| **사운드** | Web Audio 오실레이터로 **합성**한다. 오디오 파일이 없다 |
| **목숨 / 재시작** | 첫 게임에 없던 상태 |

확정값(해상도·배율·합격 기준)은 **여기 적지 않는다** —
원장(`.claude/HtmlToUnity_작업내역_Pac-Man-Game.md`)이 정본이다.
