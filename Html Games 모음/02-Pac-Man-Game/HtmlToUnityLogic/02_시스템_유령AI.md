# 02 시스템 — 유령 (「AI」가 아니다)

## 무엇인가

⚠ **추적하지 않는다.** 팩맨 위치를 **한 번도 읽지 않는다.**
직진하다 벽에 부딪히면 **무작위**로 방향을 고른다 (180도 회전만 제외).

「유령 AI」라는 이름으로 옮기면 **없는 것을 만들게 된다.**

## 상태

| 유령 | 시작 칸 | 시작 방향 | 색 |
|---|---|---|---|
| 0 | `13, 14` | `+1, 0` (오른쪽) | `#ff4b4b` |
| 1 | `14, 14` | `-1, 0` (왼쪽) | `#4bc6ff` |

**속도는 코드에 박혀 있다** — `const speed = 6 * deltaSeconds` (`281`).
팩맨(8)보다 **느리다**. 유령 객체에는 `speed` 필드가 없다.

## 계산식 — `moveGhost` (280~313)

```
speed = 6 * deltaSeconds
newX = x + dirX * speed
newY = y + dirY * speed
nextCol = round(newX)   nextRow = round(newY)

if (isWall(nextCol, nextRow))
    후보 = 상하좌우 4방향에서 «현재 방향의 반대»를 뺀 3방향
    선택 = 후보[floor(random() * 후보수)]
    dir = 선택
    return            ← ★ 이번 프레임은 «이동하지 않는다»

x = newX; y = newY
if (x < 0)        x = cols - 1     ← ★ 이동 «뒤»에 랩
if (x > cols - 1) x = 0
```

⚠ **[이상 후보 #2] 방향 전환 시 그 프레임은 못 움직인다.** `return` 이 이동을 건너뛴다.
⚠ **[이상 후보 #3] 새로 고른 방향이 벽인지 확인하지 않는다.**
   벽을 고르면 다음 프레임에 또 부딪혀 또 무작위로 고른다 — **제자리에서 떨 수 있다.**
⚠ **[이상 후보 #4] 터널 랩 순서가 팩맨과 다르다.**
   팩맨: 랩 → 벽 판정 → 이동. 유령: 이동 → 랩.

⚠ **`Math.random()` 이 여기 하나뿐이다.** 결정성(G3)과 골든 벡터가 전부 이 한 곳에 걸린다 —
이관 시 **주입식 RNG** 로 세운다 (게임 코드에 검증용 문을 뚫지 않는다).

## 충돌 — `checkCollisions` (322~336)

```
유령마다:
  if (유클리드 거리(유령, 팩맨) < 0.7)
      사망음
      lives--
      if (lives <= 0) gameOver = true; 100ms 뒤 alert("Game Over!")
      resetEntities()
      break          ← 한 프레임에 한 번만 처리
```

⚠ **거리는 유클리드 0.7 칸.** 칸 일치가 아니다.
⚠ **`resetEntities()` 는 맵을 안 건드린다** — 먹은 펠릿은 그대로다.
⚠ **`break` 로 한 번만** 처리한다. 두 유령에 동시에 닿아도 목숨은 1만 준다.

## 이 시스템이 그리는 것

⚠ **[이상 후보 #5] 유령은 «반올림 좌표»로 그려진다** (`drawGhost` 421~422).

```
gx = round(ghost.x) * corridorTile + corridorTile/2
```

이동은 연속인데 **그림은 칸 단위로 튄다.** 팩맨은 연속 좌표로 그려진다 (`drawPacman` 387~388) —
**두 개체의 움직임이 눈에 다르게 보인다.** 원본 주석은 「벽에 걸쳐 보이지 않게」라고 적고 있다.
