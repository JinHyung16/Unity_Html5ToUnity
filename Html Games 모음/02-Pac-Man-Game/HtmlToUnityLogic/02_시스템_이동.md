# 02 시스템 — 이동 (팩맨)

## 무엇인가

격자 좌표계 위를 **실수 좌표로 연속 이동**한다. 칸 단위 점프가 아니다.
방향 전환은 **예약 → 정렬 조건 충족 시 반영**의 두 단계다.

## 상태

| 이름 | 초기값 | 무엇 |
|---|---|---|
| `x`, `y` | `1`, `29` | **실수** 격자 좌표 |
| `dirX`, `dirY` | `0`, `0` | 현재 방향 (멈춤 = 둘 다 0) |
| `nextDirX`, `nextDirY` | `0`, `0` | **예약된** 방향 |
| `speed` | **8** | 초당 이동 칸 수 |

## 계산식

```
speedPerFrame = speed * deltaSeconds
newX = x + dirX * speedPerFrame
newY = y + dirY * speedPerFrame
```

### 방향 전환 — `handleInput` (213~232)

```
centerCol = round(x)   centerRow = round(y)
offsetX = |x - centerCol|   offsetY = |y - centerRow|
aligned = offsetX < 0.35 && offsetY < 0.35
stopped = dirX === 0 && dirY === 0

if (aligned || stopped)
    목표칸 = (centerCol + nextDirX, centerRow + nextDirY)
    if (목표칸이 벽이 아니면) dir = nextDir
```

⚠ **정렬 창이 `0.35` 다.** 칸 중심에서 0.35칸 안이면 전환을 허용한다 —
**엄밀한 격자 정렬을 요구하지 않는다.** 이 값이 조작감을 만든다.

⚠ **`stopped` 면 정렬과 무관하게 허용**한다. 첫 입력이 먹히게 하려는 것이다.

### 벽 판정과 스냅백 — `movePacman` (244~256)

```
nextCol = round(newX)   nextRow = round(newY)
if (isWall(nextCol, nextRow))
    dx = dirX; dy = dirY
    dir = 0
    x = nextCol - dx        ← ★ 스냅백
    y = nextRow - dy
    return
```

⚠ **[이상 후보 #1] 벽에 부딪히면 위치가 «순간이동»한다.**
현재 위치를 되돌리는 것이 아니라 **벽 칸에서 진행 방향만큼 뺀 자리**로 옮긴다.
정렬이 어긋난 상태로 벽에 닿으면 **눈에 보이는 튐**이 생길 수 있다 —
**실측으로 확증한 뒤** 「재현/수정」을 확정한다.

### 터널 랩 (240~242)

```
if (newX < 0)         newX = cols - 1
if (newX > cols - 1)  newX = 0
```

⚠ **가로만 랩한다.** 세로 랩은 없다.
⚠ **벽 판정 «전»에 랩한다** — 유령과 순서가 다르다 (`02_시스템_유령AI.md`).

### 펠릿 (261~274)

```
col = round(x)   row = round(y)
if (map[row][col] === 2 or 3)
    소리 재생
    2 이면 +10, 3 이면 +50
    map[row][col] = 0
    pelletsRemaining--
    if (pelletsRemaining <= 0) gameOver = true; 100ms 뒤 alert
```

⚠ **파워펠릿(3)에 효과가 없다.** 점수만 다르다 — 유령 상태를 건드리지 않는다.

## 파생 · 폴백

| 자리 | 거동 |
|---|---|
| `isWall` 경계 밖 | **벽으로 친다** (`203~206`) — 랩이 가로에만 있는 이유 |
| `map[row]` 없음 | 펠릿 판정에서 `map[row] &&` 로 막는다 |
