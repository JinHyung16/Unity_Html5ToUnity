# 00 게임개요 — Pac-Man-Game

## 한 판의 흐름

```
페이지 로드 → 맵 생성 · 개체 배치 → 루프 시작 (입력 대기)
   │
   │  방향 입력 → 팩맨이 그 방향으로 계속 이동
   │  펠릿을 먹는다 → 점수 (+10 / 파워펠릿 +50)
   │  유령과 거리 0.7 미만 → 목숨 -1 · 개체만 리셋 (맵은 그대로)
   │
   ├─ 펠릿을 다 먹으면 → gameOver + alert("You cleared the maze!")
   └─ 목숨이 0 이 되면 → gameOver + alert("Game Over!")

Restart 버튼 → 점수 0 · 목숨 3 · 맵 재생성 · 개체 리셋
```

주의: `gameOver` 뒤에도 그리기는 계속 돈다. 갱신만 멈춘다 (`loop` 455~469).

## 재화 · 상태

| 무엇 | 초기값 | 어떻게 변하나 |
|---|---|---|
| 점수 | 0 | 펠릿 +10 · 파워펠릿 +50 |
| 목숨 | 3 | 유령과 충돌 시 -1. 0 이면 게임 오버 |
| 남은 펠릿 | 맵의 `2`+`3` 개수 | 먹을 때마다 -1. 0 이면 클리어 |

## 진행 체인

레벨 하나뿐. 클리어하면 `alert` 만 뜨고 멈춘다.

## 저장되는 것

없음. `localStorage`·쿠키 미사용. 새로고침하면 처음부터 (Candy Crush 와 같다).

## 원본에 없는 것 — 만들면 안 되는 것

| 흔히 만들게 되는 것 | 원본에 있나 | 근거 |
|---|---|---|
| 파워펠릿으로 유령을 먹기 | 없음. 50점만 준다 | `movePacman` 262~266 — 상태 변화 없음 |
| 유령이 팩맨을 추적 | 없음. 벽에 부딪힐 때만 무작위 전환 | `moveGhost` 288~303 |
| 레벨 2 이상 | 없음 | 클리어 시 `alert` 뿐 |
| 일시정지 | 없음 | — |
| 최고 점수 / 랭킹 | 없음 (저장 없음) | — |
| 시작 화면 / 모드 선택 | 없음. 로드 즉시 시작 | `508~511` |
