# 01 게임플로우

## 화면 전이 그래프

```
[게임 화면]  ← 화면이 «하나»뿐이다. 전이가 없다.
   │ 펠릿 전멸 → alert("You cleared the maze! 🎉")   (100ms 뒤)
   └ 목숨 0   → alert("Game Over!")                 (100ms 뒤)
```

⚠ **원본에 화면 전환이 없다.** 시작 화면도, 결과 화면도, 모드 선택도 없다 —
로드되면 바로 게임이고 끝나면 `alert` 뿐이다. **만들면 「원본에 없는 창」이다.**

### 원본에 **없는** 화면

| 흔히 만들게 되는 것 | 근거 |
|---|---|
| 시작 / 타이틀 화면 | `508~511` 로드 즉시 시작 |
| 게임 오버 화면 | `alert` 한 줄 (`checkCollisions` 331) |
| 클리어 화면 | `alert` 한 줄 (`movePacman` 272) |
| 일시정지 | 정지 코드 없음 |

## 입력 전수

| 원본 | 무엇 | 원본 위치 |
|---|---|---|
| `ArrowUp` · `w` · `W` | `trySetDirection(0,-1)` | `471~501` |
| `ArrowDown` · `s` · `S` | `trySetDirection(0,1)` | 같음 |
| `ArrowLeft` · `a` · `A` | `trySetDirection(-1,0)` | 같음 |
| `ArrowRight` · `d` · `D` | `trySetDirection(1,0)` | 같음 |
| `#restartBtn` 클릭 | `restartGame()` | `503~506` |

⚠ **키 입력과 Restart 클릭 둘 다 `startBackgroundSound()` 를 부른다.**
브라우저가 사용자 제스처 없이는 오디오를 못 켜기 때문이다 —
**첫 입력이 있어야 배경 사이렌이 시작된다.**

⚠ **`trySetDirection` 은 방향을 «예약»만 한다.** 실제 전환은 `handleInput` 이
정렬 조건을 보고 결정한다 (`02_시스템_이동.md`).

## 메인 루프

| 항목 | 값 | 원본 위치 |
|---|---|---|
| 루프 | `requestAnimationFrame` | `455~469` · `511` |
| dt | `(timestamp - lastTime) / 1000` — **초 단위 실수** | `457~458` |
| dt 상한 | **없다** — 탭을 숨겼다 돌아오면 큰 dt 가 그대로 들어간다 | — |
| 순서 | `movePacman(dt)` → `유령마다 moveGhost(dt)` → `checkCollisions()` → `draw()` | `461~467` |
| 정지 게이트 | `gameOver` 면 갱신 3개를 건너뛴다. **`draw()` 는 계속 돈다** | `461` |
| `gameTime` | `timestamp / 1000` — **절대 시각**. 입 애니메이션이 여기 걸려 있다 | `459` |

⚠ **`gameTime` 이 절대 시각이라 일시정지 개념이 없다.**
게임이 멈춰도 입은 계속 움직인다 — 이관 시 **그대로 재현**할지 확정 대상이다.
