# 05 연출 — 캔버스 드로잉 + 사운드 전수

## ⚠ 원본에 이미지 파일이 **0개**다

전부 캔버스 드로잉이다. 첫 게임(Candy Crush)은 원격 PNG 를 참조했지만
**여기는 그리는 코드가 곧 그림**이다 — 우리가 **전부 만들어야 한다** (`06_리소스.md`).

### 팩맨 입 애니메이션

```
chompSpeed = 18
mouthOpen  = 0.08 + 0.28 * (0.5 + 0.5 * sin(gameTime * 18))
```

⚠ **`gameTime` 은 절대 시각**(`timestamp/1000`)이다 — 게임이 멈춰도 입은 움직인다.
⚠ 입 벌림은 **라디안**이고 0.08~0.36 사이를 오간다.

### 방향별 각도

| 방향 | `angleOffset` |
|---|---|
| 오른쪽 (`dirX=1`) | `0` |
| 왼쪽 (`dirX=-1`) | `π` |
| 위 (`dirY=-1`) | `-π/2` |
| 아래 (`dirY=1`) | `π/2` |
| 멈춤 | `0` (오른쪽을 본다) |

### 그리기 순서

`clearRect` → `drawMap` → `drawPacman` → `유령들` (`448~453`).
**유령이 가장 위**다.

## 사운드 — Web Audio 합성 (파일 없음)

**확정 B: 미리 구워서(wav) 재생하되 원본과 같아야 한다.**
아래가 **구울 때 쓰는 정본 파라미터**이고, 구운 결과가 이 수식과 맞는지 검산한다.

### ① 배경 사이렌 — `startBackgroundSound` (94~117)

| 항목 | 값 |
|---|---|
| 파형 | **sawtooth** |
| 시작 주파수 | **200 Hz** |
| 게인 | **0.04** (고정) |
| 변조 | `freq = 180 + 130 * sin(t * 0.85)` — **t 는 `Date.now()/1000`** |
| 변조 주기 | `2π / 0.85` ≈ **7.39초** |
| 주파수 범위 | **50 ~ 310 Hz** |
| 갱신 | `setInterval` **80ms** · `setTargetAtTime(…, 0.08)` 로 부드럽게 |
| 수명 | **끝나지 않는다** — 한 번 켜지면 계속 |

⚠ **`Date.now()` 기반이라 «켠 시점」과 무관하게 위상이 정해진다.**
구울 때는 **한 주기(7.39초)를 루프로** 만드는 것이 자연스럽다 — 다만
**원본은 절대 시각 위상**이라 완전히 같지는 않다. 「의도된 차이」 등재 대상.

### ② 펠릿 — `playPelletSound` (119~135)

| 항목 | 값 |
|---|---|
| 파형 | **square** |
| 주파수 | **680 Hz** (고정) |
| 게인 | 0.12 → **지수 감쇠** → 0.01 |
| 길이 | **0.06초** |

### ③ 사망 — `playDeathSound` (137~154)

| 항목 | 값 |
|---|---|
| 파형 | **sawtooth** |
| 주파수 | 220 Hz → **지수 하강** → 55 Hz |
| 게인 | 0.15 → **지수 감쇠** → 0.01 |
| 길이 | **0.6초** |

### 켜지는 시점

⚠ **첫 키 입력 또는 Restart 클릭 때 배경음이 시작된다** (`472` · `504`).
브라우저가 사용자 제스처 없이 오디오를 못 켜기 때문이다 —
**유니티에는 그 제약이 없다.** 그대로 재현할지 확정 대상이다.
