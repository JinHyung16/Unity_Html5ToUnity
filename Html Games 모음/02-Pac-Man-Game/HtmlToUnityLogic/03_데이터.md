# 03 데이터 — 곧 JSON 설계도

## 맵 레이아웃

**28열 × 31행 문자열 31줄** (`script.js` 19~50).

| 문자 | 뜻 | **개수 (실측)** |
|---|---|---|
| `0` | 빈칸 (펠릿 없음) | **55** |
| `1` | 벽 | **449** |
| `2` | 펠릿 (+10) | **360** |
| `3` | 파워펠릿 (+50) | **4** |
| | 합계 | **868** = 28 × 31 ✅ |

**펠릿 총합 = 364** (`2` 360 + `3` 4). 이 값이 클리어 조건의 분모다.

**파워펠릿 위치 (row, col)** — `(3,1)` · `(3,26)` · `(24,1)` · `(24,26)`.
네 모서리 부근이다. ⚠ 코드를 눈으로 읽었을 때 「3·4행」으로 봤는데 **실제는 3행 하나**였다 —
**세어서 확인한 값이 정본이다.**

**시작 칸 확인** — 팩맨 시작 `(1,29)` 의 칸값은 `2`(펠릿)다.
즉 **시작하자마자 발밑 펠릿을 먹는다.** 유령 시작 `(13,14)`·`(14,14)` 는 둘 다 `0`(빈칸)이다.
