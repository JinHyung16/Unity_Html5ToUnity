# 00 게임개요 — Design

> 규격은 `.claude/skills/htmltounity/references/분석로직.md`.
> **원본 라인은 인용할 때마다 grep 으로 재확정한다.** 아래 라인은 학습 1회차에 grep 으로 확정한 값이다.
> 확인 못 한 것은 「미확인」, 재지 못한 것은 「미측정(사유)」.

**상태: 1회차 작성**

## 장르

매치-3 퍼즐. 8×8 보드에서 인접한 두 사탕을 교환해 같은 색 3~4개를 만들어 없앤다.

## 한 판의 흐름

```
모드 선택 화면 (#modeSelection, 시작 시 유일하게 보이는 화면)
  ├─ [Endless Mode] ─┐
  └─ [Timed Mode]  ──┤
                     ↓
              startGame(mode)              script.js:187
              · 모드 선택 화면 숨김
              · 보드·스코어보드 표시
              · createBoard()  ← 8×8 랜덤 생성
              · score = 0
              · setInterval(gameLoop, 100)
                     ↓
              플레이 (드래그로 인접 교환 → 매치 → 제거 → 낙하 → 재생성)
                     │
     ┌───────────────┴────────────────┐
     │ Timed: 120초 경과               │ 언제나: [Change Mode]
     ↓                                ↓
 endGame()  script.js:225        changeMode()  script.js:232
 · gameInterval 정지               · gameInterval 정지
 · 전 칸 draggable=false           · (timed면) timerInterval 정지
 · alert("Time's Up! …")           · 보드·스코어보드 숨김
 · **화면은 그대로 남는다**          · 모드 선택 화면 표시
   (재시작 버튼 없음.
    [Change Mode] 로만 빠져나간다)
```

⚠ **Endless 모드에는 종료 조건이 없다.** 원본에 게임 오버·클리어 판정이 존재하지 않는다
(`script.js` 전체에 `endGame` 호출이 `timeLeft <= 0` 한 곳뿐 — `script.js:203~205`).

⚠ **「더 이상 매치가 불가능한 상태」 판정이 원본에 없다.** 데드락 검사·셔플이 없다.

## 재화

| 재화 | 획득처 | 소비처 | 표기 | 원본 위치 |
|---|---|---|---|---|
| **점수(score)** | 3매치 **+3** · 4매치 **+4** | **없음** (소비처가 없다) | `<h1 id="score">` 에 정수 그대로 | `script.js:18` 선언 · `130`·`143`·`157`·`170` 가산 |

**재화는 점수 하나뿐이다.** 코인·하트·이동 횟수 같은 것이 원본에 없다.

⚠ **`localStorage` · `sessionStorage` · 쿠키를 원본이 전혀 쓰지 않는다.**
`grep -n "localStorage|sessionStorage|document.cookie" script.js` → **0건** (학습 1회차 확인).
**「저장 없음」이 확인된 사실이다.** 새로고침하면 점수가 사라지는 것이 원본 사양이다.
