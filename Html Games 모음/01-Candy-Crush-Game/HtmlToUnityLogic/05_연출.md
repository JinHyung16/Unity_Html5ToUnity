## 그림자 · 반투명 전수표

| 셀렉터 | 속성 | 값 | 알파 | 원본 위치 | 흡수 방법 |
|---|---|---|---|---|---|
| `.grid` | `box-shadow` (inset) | `0 2px 4px rgba(0,0,0,0.5) inset` | 0.5 | `style.css:20` | 미정 — 9-slice 스프라이트에 구울지 UI Shadow 로 할지 |
| `.grid` | `box-shadow` (outer) | `0 1px 0 #fff` | 1 | `style.css:20` | 미정 — blur 0 이라 1px 흰 선이다 |
| `.grid` | `background-color` | `rgba(109,127,151,0.5)` | 0.5 | `style.css:17` | Image 색 알파 0.5 |

색공간은 Linear, 알파 역산은 하지 않는다 (확정표 6번). 어긋남은 리소스 자체 또는 프리팹 세팅(「흡수 방법」 칸)에서 흡수한다. 원본 알파값(0.5)은 이 표에 그대로 둔다.

주의: `0 1px 0 #fff` 는 blur 0 인 아래쪽 1px 흰 하이라이트 선이다. Soft Shadow 를 넣으면 원본과 다르다.
