## id / 클래스 → 실제 화면 대응표

| 원본 id/class | 실제 화면 | 비고 |
|---|---|---|
| `#modeSelection` | 모드 선택 화면 | **이름과 역할이 일치한다** |
| `.scoreBoard` | 게임 화면 상단 정보판 | 점수·타이머·모드변경 버튼을 **한 덩어리**로 들고 있다 |
| `.grid` | 보드 | `#grid` 가 아니라 **클래스**다 |
| `#score` | 점수 **숫자만** (`h1`) | 라벨 `score` 는 형제 `h3` 다. **둘을 한 요소로 오해하기 쉽다** |
| `#timer` | 타이머 텍스트 | Endless 에서 **빈 문자열**이라 크기 0 |
| `#changeMode` | 모드 변경 버튼 | **스코어보드 안에** 있다 |

> ⚠ **`#score` 는 숫자만이다.** 캡처만 보면 `SCORE / 0` 이 한 덩어리로 보이지만
> DOM 은 `h3` + `h1` **두 요소**다 (분석로직 「오염 갈래 — 캡처를 사양으로 삼음」).
