# HtmlToUnityLogic — 학습 단계 산출물 (Candy-Crush-Game)

원본을 **실제로 돌려 보며** 파악한 것을 정리한다. 규격은 `분석로직.md` 「HtmlToUnityLogic/」.
이관 담당자는 이 문서들을 근거로 작업한다.
단, **최종 판정은 언제나 원본 코드다** — 여기 적힌 요약을 최종 근거로 쓰지 않는다.

원본 실행: `python -m http.server 8123` → `http://127.0.0.1:8123/index.html`
원장: `<Unity 저장소>/.claude/HtmlToUnity_작업내역_Candy-Crush-Game.md`
