# 02 시스템 · 게임모드 — Design + Client (최종 기입 Client)

규격: `.claude/skills/htmltounity/references/분석로직.md`
원본 라인은 인용할 때마다 grep 으로 재확정한다. 아래 라인은 1회차 grep 확정값이다.

상태: 1회차 작성

## 무엇인가

Endless 와 Timed 두 모드. 보드·매치·점수 규칙은 같고 타이머 유무만 다르다.

## 상태

| 변수 | 자료형 | 초기값 | 저장되나 | 원본 위치 |
|---|---|---|---|---|
| `currentMode` | string / null | null | 아니오 | `script.js:19` · `188` |
| `timeLeft` | int | 0 | 아니오 | `script.js:20` · `198` |
| `gameInterval` | id / null | null | 아니오 | `script.js:21` · `195` |
| `timerInterval` | id / null | null | 아니오 | `script.js:22` · `200` |

`currentMode` 값은 `"endless"` / `"timed"` 문자열이다 (`script.js:243~244`).
Unity 에서는 enum 이다 (SKILL 「판별 어휘가 `string` 컬럼이다 → enum 이다」). 세이브 키가 아니므로 전환 제약이 없다.

## 모드별 차이 전수표

| 항목 | Endless | Timed | 원본 위치 |
|---|---|---|---|
| 제한 시간 | 없음 | 120초 | `script.js:197~198` |
| 타이머 표시 | `#timer` 를 빈 문자열로 비운다 | `Time Left: M:SS` | `script.js:209` · `218` |
| 타이머 틱 | 없음 | 1000 ms | `script.js:200~207` |
| 종료 조건 | 없음 | `timeLeft <= 0` | `script.js:203` |
| 종료 시 처리 | — | `endGame()` | `script.js:205` |
| 점수 처리 | 같음 (+3 / +4) | 같음 | — |
| 보드 생성 | 같음 | 같음 | `script.js:192` |
| 재시작 경로 | `[Change Mode]` → 모드 선택 | 같음 | `script.js:245` |

차이는 이 표가 전부다. 난이도·속도·색 수·보드 크기는 모드와 무관하다.

## 시작

```js
// script.js:187~211
function startGame(mode) {
    currentMode = mode;
    modeSelection.style.display = "none";
    grid.style.display = "flex";
    scoreDisplay.parentElement.style.display = "flex";   // .scoreBoard
    createBoard();
    score = 0;
    scoreDisplay.innerHTML = score;
    gameInterval = setInterval(gameLoop, 100);

    if (mode === "timed") {
        timeLeft = 120;
        updateTimerDisplay();
        timerInterval = setInterval(() => {
            timeLeft--;
            updateTimerDisplay();
            if (timeLeft <= 0) { clearInterval(timerInterval); endGame(); }
        }, 1000);
    } else {
        timerDisplay.innerHTML = "";
    }
}
```

순서: `createBoard()` 가 `score = 0` 보다 먼저 온다. 보드 생성은 점수를 안 올려 결과는 같다. 첫 `gameLoop` 는 `setInterval` 후 100ms 뒤다.

스코어보드는 `scoreDisplay.parentElement` 로 켠다(`#score` 의 부모가 `.scoreBoard` 인 DOM 구조 의존). Unity 에서는 스코어보드를 직접 참조한다.

## 타이머 표기

```js
// script.js:214~222
function updateTimerDisplay() {
    if (currentMode === "timed") {
        let minutes = Math.floor(timeLeft / 60);
        let seconds = timeLeft % 60;
        timerDisplay.innerHTML = `Time Left: ${minutes}:${seconds.toString().padStart(2, "0")}`;
    } else {
        timerDisplay.innerHTML = "";
    }
}
```

| 항목 | 사양 |
|---|---|
| 포맷 | `Time Left: M:SS` — 분은 패딩 없음, 초만 2자리 |
| 120초 시작 표기 | `Time Left: 2:00` |
| 59초 표기 | `Time Left: 0:59` |
| 0초 도달 | `timeLeft--` 로 0이 되면 `Time Left: 0:00` 을 한 번 그린 뒤 `endGame()` |
| 음수 | `timeLeft <= 0` 에서 `clearInterval` 하므로 −1 은 안 뜬다 |

문구는 바이트 단위로 같아야 한다 (`Time Left: ` — 콜론 뒤 공백 1칸).

## 종료

```js
// script.js:225~229
function endGame() {
    clearInterval(gameInterval);
    squares.forEach(square => square.setAttribute("draggable", false));
    alert(`Time's Up! Your score is ${score}`);
}
```

| 하는 일 | 안 하는 일 |
|---|---|
| 게임 루프 정지 | 점수 초기화 안 함 |
| 전 칸 `draggable=false` | 보드 숨김 안 함 — 화면에 그대로 남는다 |
| `alert` 모달 | 재시작 버튼 없음 |

`alert()` 문구는 `Time's Up! Your score is <점수>` (아포스트로피 포함). Unity 대응물이 없어 원본에 없는 팝업을 만든다. 사양은 `01_게임플로우.md`.

주의: `draggable=false` 잠금은 영구가 아니다. `changeMode` 후 재진입하면 `createBoard()` 가 `draggable=true` 로 새로 만든다 (`script.js:39`).

## 모드 전환

```js
// script.js:232~240
function changeMode() {
    clearInterval(gameInterval);
    if (currentMode === "timed") { clearInterval(timerInterval); }
    grid.style.display = "none";
    scoreDisplay.parentElement.style.display = "none";
    modeSelection.style.display = "flex";
}
```

| 초기화되는 것 | 초기화 안 되는 것 |
|---|---|
| 게임 루프 · 타이머 루프 | `score` (다음 `startGame` 에서 0이 된다) |
| 화면 표시 상태 | `currentMode` (그대로 남는다) |
| — | `timeLeft` (그대로 남는다) |
| — | 보드 내용 (`.grid` 의 div 들이 살아 있다) |

`timeLeft` 가 안 지워진다. Timed 재진입은 `startGame` 이 120으로 덮어 결과가 같다. Endless 재진입 시 이전 값이 남고 아무도 읽지 않는다.

`endGame()` 뒤 `changeMode()` 를 누르면 이미 정지된 `gameInterval` 에 `clearInterval` 이 다시 불린다. JS 에서는 무해하나 Unity 에서 그대로 옮기면 이중 해제가 될 수 있다.
